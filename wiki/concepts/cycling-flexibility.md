# Cycling Flexibility Work

## Summary

Flexibility work for cyclists is a core component of [[concepts/strength-and-conditioning-for-cyclists|strength and conditioning]] programming — typically six key exercises selected and adapted to each rider's specific imbalances and movement restrictions, rather than a fixed routine [[sources/pdf-d2f73a919c86]].

## Key claims

- Mosley's guide singles out six key flexibility exercises as the recommended core set for cyclists [[sources/pdf-d2f73a919c86]].
- The prescription is explicitly individualised: cyclists should select stretches specific to their own requirements, treating the listed exercises as a guide rather than a rigid list [[sources/pdf-d2f73a919c86]].
- The cycling-specific rationale for flexibility is supporting range of movement, coordination, agility, and stability alongside strength — i.e., flexibility sits in the same prescription as the strength sessions, not as a separate 'wellness' practice [[sources/pdf-d2f73a919c86]].
