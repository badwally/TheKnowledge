# Hazard function

## Summary

The hazard function characterizes the time-dependent failure rate of a component. In mobile-work-equipment prognostics it is generally complex and is best modeled via non-parametric estimators, with parametric Generalized-gamma and Weibull models appropriate only for notable exceptions.

## Key claims

- The hazard function characterizes time-dependent failure probabilities of machine components in predictive-maintenance applications [[sources/pubmed-35595821]].
- The hazard functions obtained for different machine components from mobile work equipment are complex and versatile and are best modeled via non-parametric estimators [[sources/pubmed-35595821]].
- Notable exceptions exist where individual machine components have hazard functions amenable to parametric Generalized-gamma and Weibull models [[sources/pubmed-35595821]].
