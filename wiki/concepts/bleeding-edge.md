# Bleeding Edge (SRAM)

## Summary

"Bleeding Edge" is SRAM's name for a caliper bleed-port design used on some [[entities/sram-hrd|HRD]] brakes; it has its own dedicated [[concepts/brake-bleed|bleed procedure]], distinct from the procedure for non-Bleeding Edge calipers [[sources/pdf-b51938faf250]].

## Key claims

- SRAM's HRD service manual documents two bleed procedures and labels them "Bleeding Edge Bleed Procedure" and "Non-Bleeding Edge Bleed Procedure" — i.e., the port type drives which procedure applies [[sources/pdf-b51938faf250]].
- Identifying which procedure to follow begins with caliper identification: a step titled "Caliper Identification" precedes both bleed procedures in the manual [[sources/pdf-b51938faf250]].
