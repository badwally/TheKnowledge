# Differential Program Induction

## Summary

A line of neuro-symbolic research that learns explanatory logic rules from noisy data — upgrading inductive logic programming to model neural predicates learned from data — and that can also use programs to enforce structure in neural predictions; described by Belle and Marcus (AAAI-26) as one of the seven representative areas of inquiry in neuro-symbolic AI [[sources/pdf-vaishak-belle-2026-the-future-is]].

## Key claims

- Program induction is a major area in computer science (Gulwani 2010), and differential program induction is its differentiable, neural-friendly variant [[sources/pdf-vaishak-belle-2026-the-future-is]].
- A notable example is work from Google DeepMind (Evans and Grefenstette 2018) on learning explanatory logic rules from noisy data, which upgrades inductive logic programming to model neural predicates learned from noisy data [[sources/pdf-vaishak-belle-2026-the-future-is]].
- A related but somewhat orthogonal paradigm uses programs to enforce structure in neural predictions, as seen in concept learning (Lake, Salakhutdinov, and Tenenbaum 2015) [[sources/pdf-vaishak-belle-2026-the-future-is]].
- Differential program induction can be extended to dynamic settings such as reinforcement learning (Belle and Bueff 2023; Bueff and Belle 2024) [[sources/pdf-vaishak-belle-2026-the-future-is]].
- Work on how program induction might affect human comprehension is referenced via Rule et al. (2024) [[sources/pdf-vaishak-belle-2026-the-future-is]].
