# Long COVID nutrient deficit lab panel

## Summary

The baseline-clearance lab panel required by Dr. Carla Kuon's UCSF Osher Long COVID group medical visits, spanning inflammatory markers (hsCRP, ESR), mast-cell mediators (histamine, tryptase), and a focused micronutrient set (vitamin B2, ferritin, vitamin D, vitamin A, zinc, copper) with explicit per-analyte target ranges and intervention thresholds [[sources/pdf-50a1f07b475f]].

## Key claims

- Required panel: vitamin B2, ferritin, histamine, tryptase, high-sensitivity CRP, ESR, vitamin D, vitamin A, zinc, copper [[sources/pdf-50a1f07b475f]].
- Vitamin B2 should sit in the mid-to-upper range of normal because it recycles glutathione, helps clear histamine, and supports brain and nerve function [[sources/pdf-50a1f07b475f]].
- Ferritin should be ≥100 ng/dl; otherwise iron supplementation is indicated. Low ferritin contributes to a hypoxic state and promotes classic inflammation, and iron is needed to clear histamine [[sources/pdf-50a1f07b475f]].
- Vitamin D goal >40, ideally 50–60, especially in autoimmune illness; vitamin D lowers CRP, ESR, and classic inflammatory pathways, and low vitamin D has been associated with higher COVID mortality and higher degree of Long COVID [[sources/pdf-50a1f07b475f]].
- Vitamin A: if low or borderline, take 8,000–10,000 units daily for 1 month; vitamin A is essential for lymphocyte function [[sources/pdf-50a1f07b475f]].
- Zinc and copper should each be approximately 100 ng/dl on a 0.8–1 to 1/1 ratio; if zinc is much lower than copper, this can present as anxiety/depression because zinc is a cofactor for dopamine production, and zinc is also needed for immune function [[sources/pdf-50a1f07b475f]].
- The panel is issued under Dr. Kuon's NPI 199272839 and ICD-10 code U09.9, with results faxed to 415-353-7358 [[sources/pdf-50a1f07b475f]].
