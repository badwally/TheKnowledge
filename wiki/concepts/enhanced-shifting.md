# Enhanced Shifting (eTap AXS)

## Summary

Enhanced Shifting is an alternative shift mode for the [[entities/sram-etap-axs|eTap AXS]] groupset — documented in the systems manual as a distinct mode from the default "Shifting" and from "AXS Button Shifting" — that changes how shifts are coordinated [[sources/pdf-f13aa755f8e2]].

## Key claims

- The eTap AXS Systems User Manual lists "Enhanced Shifting" as its own dedicated section, placed after "AXS Button Shifting" — indicating it is a configurable alternative mode rather than the system's default behaviour [[sources/pdf-f13aa755f8e2]].
- It is translated across SRAM's nine-language documentation as "Erweiterter Schaltmodus / Cambio mejorado / Passage des vitesses amélioré / Cambio avanzato / Geavanceerd schakelen / Modo Realçado de Meter Mudanças / パワーアップしたシフティング / 增强型变速" — consistently framed as an upgraded or expanded shift mode [[sources/pdf-f13aa755f8e2]].
