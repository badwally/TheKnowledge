# LLM-Based Data Cleaning Agents

## Summary

LLM-based data cleaning agents are agentic systems built around large language models that perform error detection, correction, and standardisation on tabular or semi-structured records. In the context of Predictive Maintenance, they are positioned as an automated replacement for the time-consuming manual cleaning of equipment maintenance logs by data scientists and reliability engineers.

## Key claims

- LLM-based agents have been proposed as a way to automate the cleaning of equipment maintenance logs, replacing time-consuming manual review by data scientists and reliability engineers [[sources/web-2026-01-13-6bf]].
- A complete LLM-agent data-cleaning approach for maintenance logs comprises both the agent implementation itself and a set of metrics to assess agents' performance on the cleaning task [[sources/web-2026-01-13-6bf]].
- Empirical comparison across several LLMs on the maintenance-log cleaning task indicates that LLM-based agents are a promising solution for improving the quality of datasets used in Predictive Maintenance systems, and ultimately for developing more reliable PdM models [[sources/web-2026-01-13-6bf]].
