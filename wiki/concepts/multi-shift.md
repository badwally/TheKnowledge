# Multi-shift

## Summary

Multi-shift is an [[entities/sram-etap-axs|eTap AXS]] feature, documented in the context of e-Bike/Pedelec shifting, that lets a single rider input trigger multiple gear changes in succession [[sources/pdf-f13aa755f8e2]].

## Key claims

- The eTap AXS Systems User Manual pairs the e-Bike/Pedelec shifting topic explicitly with multi-shift — "e-Bike/Pedelec Shifting and Multi-shift" appears as a single combined section in the table of contents [[sources/pdf-f13aa755f8e2]].
- The manual translates the topic consistently across nine languages as "Mehrfach-Schalten / cambio múltiple / Multi-shift / multi-shift / Meter uma ou múltiplas mudanças / マルチシフト / 多档位变速" — i.e., "multi-shift" is the canonical concept name across SRAM's documentation, not a localised marketing term [[sources/pdf-f13aa755f8e2]].
