# Box Setup

## Summary

Box Setup is TTrades's Model 5 — a trade-entry pattern in which price forms an original consolidation range, breaks aggressively out one side, immediately reverses with an aggressive move through the other side, and is entered on the retest of the original consolidation low (bullish) or high (bearish) [[sources/pdf-3a510f58854c]].

## Key claims

- Box Setup is the only model in TTrades's framework that is structurally distinct from Models 1–4 — it does not use the HTF POI / liquidity grab / BOS + displacement + FVG scaffolding of the trigger-stack models [[sources/pdf-3a510f58854c]].
- The bullish Box Setup geometry is: an HTF POI / Low premise → Original Consolidation Range → an Aggressive Down move out of the range → an Aggressive Up move that reverses through and above the range → entry on the Retest of the Original Consolidation Low [[sources/pdf-3a510f58854c]].
- The bearish Box Setup mirrors the bullish geometry: HTF POI / High premise → Original Consolidation Range → Aggressive Up → Aggressive Down → entry on the Retest of the Original Consolidation High [[sources/pdf-3a510f58854c]].
- Both bullish and bearish Box Setups are gated on a "Good Risk : Reward" check at the entry retest [[sources/pdf-3a510f58854c]].
- The reference card includes an experimental "No POI" variation of Model 5, indicating that the consolidation-and-retest geometry can be traded without an HTF directional premise — the only TTrades model for which this is allowed [[sources/pdf-3a510f58854c]].
