# AXS Button

## Summary

The AXS Button is a dedicated, configurable button on each [[entities/sram-etap-axs|eTap AXS]] shifter — distinct from the regular shift paddle — whose function can be assigned by the rider through the [[entities/sram-axs-app|SRAM AXS App]] [[sources/pdf-f13aa755f8e2]].

## Key claims

- The eTap AXS Systems User Manual treats "AXS Button Functions" and "AXS Button Shifting" as discrete sections, indicating the button has both a configuration step (assigning what it does) and an in-ride behaviour (shifting via the button) [[sources/pdf-f13aa755f8e2]].
- AXS Button Shifting is documented separately from the manual's main "Shifting" chapter, framing the button as an alternative actuation path rather than a duplicate of the standard paddle [[sources/pdf-f13aa755f8e2]].
- The button is positioned in the install flow before System Pairing — i.e., it is part of the per-shifter setup that gets paired into the system, not an external accessory [[sources/pdf-f13aa755f8e2]].
