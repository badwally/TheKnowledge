# AXS System Pairing

## Summary

System Pairing is the wireless handshake that links the components of an [[entities/sram-etap-axs|eTap AXS]] groupset — derailleurs, shifters, batteries, BlipBox — into one logical system, performed once per build before the rider can shift [[sources/pdf-f13aa755f8e2]].

## Key claims

- The eTap AXS Systems User Manual carves out a dedicated "System Pairing" step in the install flow, sitting after AXS Button function setup and before the shifting and component-install sections — i.e., pairing is a prerequisite for any shift to work [[sources/pdf-f13aa755f8e2]].
- Pairing is required because AXS components are only compatible with other AXS components, and the system has to establish which specific units belong on this bike rather than picking up signals from other AXS bikes nearby [[sources/pdf-f13aa755f8e2]].
- The manual translates the topic consistently across nine languages as "Koppeln des Systems / Emparejamiento del sistema / Synchronisation du système / Accoppiamento del sistema / Het systeem koppelen / システムのペアリング / 系统配对" [[sources/pdf-f13aa755f8e2]].
