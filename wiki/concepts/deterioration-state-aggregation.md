# Element-to-Network Deterioration State Aggregation

## Summary

Element-to-network deterioration-state aggregation is the method that combines element-level posterior condition estimates upward through a hierarchy — category, bridge, and finally network — so that decision-makers can read a single condition figure at any chosen level of the asset-management hierarchy.

## Key claims

- An aggregation method is required to combine deterioration-state estimates from the element level up to the category level (e.g., beams, slabs), then to the bridge level, and finally to the network level [[sources/yt-vx6ATEoEuUE]].
- Each bridge contains multiple categories of structural elements, and each category in turn comprises multiple individual elements (e.g., two slabs or twenty beams) [[sources/yt-vx6ATEoEuUE]].
- The aggregation method is one of the two prerequisites — alongside handling missing data — for extending element-level deterioration analysis to a bridge network [[sources/yt-vx6ATEoEuUE]].
