# Data Poisoning

## Summary

Data poisoning is a cyber-security threat to machine-learning systems in which adversarial inputs in training data corrupt model behaviour; the ISED Voluntary Code of Conduct on Advanced Generative AI Systems names it as a specific risk that developers (and, for publicly available systems, managers) must assess and mitigate [[sources/web-2026-06-04-a90]].

## Key claims

- The ISED Voluntary Code of Conduct on Advanced Generative AI Systems requires developers of advanced generative AI systems to "perform an assessment of cyber-security risk and implement proportionate measures to mitigate risks, including with regard to data poisoning" [[sources/web-2026-06-04-a90]].
- Cyber-security assessment including data poisoning is the one Validity-and-Robustness measure that the code extends to managers (rather than only developers), and only for publicly available advanced generative systems [[sources/web-2026-06-04-a90]].
