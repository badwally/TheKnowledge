# Biomedical Data Commons

## Summary

A biomedical data commons is a centralized, cloud-based system for sharing and analyzing biomedical data — typically pairing cloud-based storage with cloud-based workspaces and portals for search and analysis — and associated with a specific funder or research initiative [[sources/web-2023-04-12-931]]. Dahlquist, Nelson, and Fullerton (2023) identify five NIH-funded examples (AoURH, AnVIL, BDC, GDC, Kids First DRC) and describe them collectively as 'platforms' or 'ecosystems' in recognition of their multi-component architecture [[sources/web-2023-04-12-931]].

## Key claims

- A 'cloud-based platform' is defined as one that pairs cloud-based data storage with search and analysis functionality via cloud-based workspaces and portals [[sources/web-2023-04-12-931]].
- A 'platform' is treated as a centralized system for data sharing associated with a specific NIH Institute or research initiative, distinguishing it from generic component infrastructure that may be shared across platforms [[sources/web-2023-04-12-931]].
- Some platforms are alternatively described as 'ecosystems' in recognition of their multiple components [[sources/web-2023-04-12-931]].
- Five NIH-funded biomedical data commons existed at the time of the 2021 analysis: All of Us Research Hub, AnVIL, BioData Catalyst, Genomic Data Commons, and Kids First Data Resource Center [[sources/web-2023-04-12-931]].
- Cloud platforms are compared against the pre-existing dbGaP mechanism, which represents the established model for genomic data sharing [[sources/web-2023-04-12-931]].
- The commons promote broad use of genomic and other biomedical data by maximizing the scientific utility of costly-to-generate genomic and linked clinical data [[sources/web-2023-04-12-931]].
- Common governance categories applicable across all surveyed commons: data submission, data ingestion, user authentication and authorization, data security, data access, auditing, and sanctions [[sources/web-2023-04-12-931]].
- Cloud-based commons share four high-level features: a formal data ingestion process, multiple tiers of data access with varying user authentication and/or authorization requirements, platform and user data security measures, and auditing for inappropriate data use [[sources/web-2023-04-12-931]].
- Commons differ in how data tiers are organized and in the specifics of user authentication and authorization across access tiers — surfacing aspects of governance that may require harmonization to achieve interoperability [[sources/web-2023-04-12-931]].
- Institutional stakeholders affected by commons governance include research participants, researchers (as both data contributors and platform users), policymakers, funders, and researchers' institutions [[sources/web-2023-04-12-931]].
- The biomedical data commons model is also relevant for navigating the NIH Data Management and Sharing Policy [[sources/web-2023-04-12-931]].
