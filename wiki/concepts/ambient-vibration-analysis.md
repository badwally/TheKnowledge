# Ambient vibration analysis

## Summary

Ambient vibration analysis is a field-testing technique in which a structure's response under operational/ambient excitation is measured to characterize its dynamic behaviour; the 2025 ITcon paper by Porto Oliveira and Dominguez Sotelino uses it as the primary SHM input for finite element model calibration of the Rio Claro Viaduct.

## Key claims

- Ambient vibration analysis was performed as part of the field-test campaign to capture the Rio Claro Viaduct's dynamic behaviour [[sources/web-2025-10-14-bcb]].
- The dynamic behaviour data obtained via ambient vibration analysis was used to calibrate a finite element model of the viaduct [[sources/web-2025-10-14-bcb]].
- This calibrated model in turn provided the simulation environment used to generate the damage scenarios that train the ANN damage-assessment models [[sources/web-2025-10-14-bcb]].
