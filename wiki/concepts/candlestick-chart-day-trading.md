# Candlestick charts for day trading

## Summary

The canonical chart type for retail day trading: candlesticks, used in a multi-timeframe stack (1-min / 5-min / 15-min / hourly / daily) to read price action. Nikonomics treats this configuration as the baseline Webull setup for any day trader and frames screen time on candlestick charts as the way price-action skill is built [[sources/pdf-5a5936689043]].

## Key claims

- Webull supports multiple chart types — line, bar, and candlestick — but Nikonomics argues candlestick charts are "BY FAR the most effective among day traders" because they pack opening and closing prices, the high and low prices, and the direction of the trend into a compact format [[sources/pdf-5a5936689043]].
- Step one of Nikonomics's chart-setup checklist is to set the chart type to candlesticks [[sources/pdf-5a5936689043]].
- Candlestick literacy is positioned as outsourceable: there is "an infinite amount of information out there on YouTube" that explains candle reading better than the book does — Nikonomics defers to a specific YouTube link as a reference [[sources/pdf-5a5936689043]].
- Pattern recognition is built on top of candlestick literacy: traders should learn basic candlestick patterns from cheat sheets, but the durable skill comes from screen time, not from memorizing patterns [[sources/pdf-5a5936689043]].
- Recommended time-frame stack for day trading on Webull: 1-minute, 5-minute, 15-minute, hourly, and daily charts — the shorter ones for executable price action, the longer ones for the bigger picture [[sources/pdf-5a5936689043]].
- Webull supports time frames ranging from 1-minute to 1-month intervals, which Nikonomics flags as the configurable surface area for the stack [[sources/pdf-5a5936689043]].
