# Ladder Set Protocol

## Summary

A ladder set protocol is a strength-training prescription that runs through ascending rep counts (e.g., 1, 2, 3, 4) within a session — the structure that [[entities/bethskw|/u/Bethskw]]'s [[entities/dfw-kettleballs-remix|DFW Kettleballs Remix]] uses to progress [[concepts/clean-and-press|clean & press]] and [[concepts/front-squat|front squat]] sets across weeks of training [[sources/pdf-8dee6c5cd58d]].

## Key claims

- The DFW Kettleballs Remix progresses the C&P/FS ladder week by week: Week 1 runs sets of 1, 2, 3; Week 3 extends to 1, 2, 3, 4; Week 4 reaches 1, 2, 3, 4, (5) — with the parenthesised top rung indicating a stretch target rather than a mandatory rep [[sources/pdf-8dee6c5cd58d]].
- Other days within the same week run flat sets — e.g., "Sets of 1," "Sets of 2," "Sets of 3" — rather than ladders, so the program intermixes ladder days with flat-set days [[sources/pdf-8dee6c5cd58d]].
- The Remix uses parentheses to mark a top-end rep that is conditionally attempted (the "(5)" in Week 4), establishing a notation convention for stretch sets within a ladder [[sources/pdf-8dee6c5cd58d]].
