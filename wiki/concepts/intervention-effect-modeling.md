# Intervention Effect Modelling for Structural Elements

## Summary

Intervention-effect modelling represents maintenance interventions on a structural element as a jump in the deterioration state — affecting both the condition trajectory and the deterioration speed — and quantifies the prior magnitude of that jump per (intervention type, element category) combination from historical inspection records.

## Key claims

- For some structural elements, interventions are observed in the historical record together with both the intervention type and the intervention date [[sources/yt-vx6ATEoEuUE]].
- Previously published work by the same research group developed a model that quantifies the jump in condition associated with each intervention type [[sources/yt-vx6ATEoEuUE]].
- The intervention model captures effects on both the condition trajectory and the deterioration speed of the structural element [[sources/yt-vx6ATEoEuUE]].
- A worked beam-reparation example demonstrates an estimated condition jump and a corresponding deterioration-speed shift at the year 2011 [[sources/yt-vx6ATEoEuUE]].
- When prior knowledge of the intervention effect for a specific (type, category) pair is unavailable, the missing prior can be replaced by the expectation of the effect of the same intervention type on other categories within the same structural-element group [[sources/yt-vx6ATEoEuUE]].
