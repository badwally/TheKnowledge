# Aerobic Capacity

## Summary

Aerobic capacity is the rate at which the [[concepts/aerobic-energy-system|aerobic system]] can produce energy, set jointly by how fast oxygen can be delivered to the working muscles and how fast those muscles can process it [[sources/pdf-21a07e2e3e63]].

## Key claims

- The 2021 guide defines aerobic capacity as the capacity of the aerobic system to produce energy, depending on the rate at which oxygen can be supplied to working muscles and the rate at which the muscles can process that oxygen [[sources/pdf-21a07e2e3e63]].
- A stronger aerobic system improves recovery between hard efforts, because aerobic metabolism is what resynthesises depleted phosphocreatine stores [[sources/pdf-21a07e2e3e63]].
- Improving aerobic capacity also lets more pyruvate be processed aerobically rather than diverted to [[concepts/lactate|lactate]] and H⁺, which delays fatigue at a given intensity [[sources/pdf-21a07e2e3e63]].
