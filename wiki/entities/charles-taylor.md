# Charles Taylor

## Summary

Charles Taylor is a named HomeRun IQ customer firm whose Project Manager Ryan Jessop is featured in HomeRun IQ's published customer testimonials, attributing a 30–40% fee impact to the templating features baked into the HomeRun IQ platform [[sources/web-2026-01-01-936]].

## Key facts

- Named customer of HomeRun IQ in the features-page testimonial copy [[sources/web-2026-01-01-936]].
- Ryan Jessop is identified as a Project Manager at Charles Taylor in the HomeRun IQ testimonial attribution [[sources/web-2026-01-01-936]].
- Attributed quantified outcome from HomeRun IQ adoption (per Jessop testimonial): 30–40% fee impact attributable to HomeRun IQ's templating features [[sources/web-2026-01-01-936]].
- The Jessop testimonial characterizes the fee impact as a function of templating features already "baked into" HomeRun IQ rather than firm-side customization effort [[sources/web-2026-01-01-936]].
