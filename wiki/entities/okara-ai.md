# Okara.ai

## Summary

Okara.ai is a Singapore-based AI marketing-agent startup founded in 2025 by Fatima Rizwan, reverse-engineered by Orita as the reference implementation for Level 0 (cron + prompt-template) agent architecture [[sources/docx-b90a5e5fdcc4]]. Orita's analysis examined a live demo account at okara.ai/agent/cmo/ on the free tier (5 credits) [[sources/docx-b90a5e5fdcc4]].

## Key facts

- Founded: 2025 by Fatima Rizwan in Singapore [[sources/docx-b90a5e5fdcc4]].
- Users: approximately 30K as of the October 2025 launch [[sources/docx-b90a5e5fdcc4]].
- Team: small, hiring founding full-stack and AI engineers [[sources/docx-b90a5e5fdcc4]].
- Pricing: Free tier (5 credits) / $99/mo Hire tier / Max tier (price undisclosed) [[sources/docx-b90a5e5fdcc4]].
- GitHub footprint: github.com/askokara with two public repos (okara-crypto in TypeScript, .github config); minimal open-source surface [[sources/docx-b90a5e5fdcc4]].
- Tech signals: TypeScript primary language, PHP + JavaScript on the web layer, Framer for the marketing site [[sources/docx-b90a5e5fdcc4]].
- Product surface: agent-style dashboard with a four-panel grid layout observed in the CMO agent demo [[sources/docx-b90a5e5fdcc4]].
- Strategic positioning for Orita: cited as the Level 0 reference implementation — task-specific prompt templates marketed as “agents,” not a true multi-agent system [[sources/docx-b90a5e5fdcc4]].
