# Hopiplaka

## Summary

Trader and author of "Demystifying ICT: What Every ICT Trader Still Wants to Know," a book published in multiple revisions during 2023 — including Version 1.0.9 (149 pages) [[sources/pdf-930894c4fbad]], Version 1.1.1 (160 pages) [[sources/pdf-94cecf7a170a]], and the later Version 1.1.3 (173 pages) [[sources/pdf-1ab14c833d75]] — that maps Inner Circle Trader (ICT) terminology onto a Tesla 3-6-9 mathematical framework via Power of 3 (PO3) dealing ranges, Goldbach/Huddleston levels, and a 20-40-60 day HIPPO look back system.

## Key facts

- Authored "Demystifying ICT" Version 1.0.9 (2023, 149 pages) [[sources/pdf-930894c4fbad]], Version 1.1.1 (2023, 160 pages) [[sources/pdf-94cecf7a170a]], and Version 1.1.3 (2023, 173 pages) [[sources/pdf-1ab14c833d75]].
- Frames the book in Version 1.0.9 as both "my view" on mapping ICT teachings onto mathematical concepts and a learning path organized around three steps — define the dealing range, define the IPDA wireframe inside the dealing range, and use the AMD cycle plus look back periods to define time levels [[sources/pdf-930894c4fbad]]; Version 1.1.1 repeats the same three-step framing in its prologue [[sources/pdf-94cecf7a170a]]; in Version 1.1.3 the same framing is repeated and the disclaimer broadened [[sources/pdf-1ab14c833d75]].
- Uses Nikola Tesla's 3-6-9 vortex numbers as the organizing principle: 3 for PO3 dealing-range price partitions, 6 for Goldbach/IPDA price levels, 9 for the 20-40-60 day look back time period [[sources/pdf-930894c4fbad]] [[sources/pdf-94cecf7a170a]] [[sources/pdf-1ab14c833d75]].
- Opens Version 1.0.9 [[sources/pdf-930894c4fbad]] and Version 1.1.1 [[sources/pdf-94cecf7a170a]] with Tesla's quote, "If only you would know the magnificence of the 3, 6, and 9, you would have a key to the universe," and uses the 3-6-9 vortex as the book's organizing principle.
- Splits the framework explicitly into PRICE (3 → PO3, 6 → IPDA) and TIME (9 → look back), framing the combination as the book's central deliverable [[sources/pdf-930894c4fbad]] [[sources/pdf-94cecf7a170a]].
- Structures the trader workflow into three steps — define the dealing range, define the IPDA wireframe inside the dealing range, and use AMD cycle plus look back periods for time levels — calling steps 1 and 2 "price levels" and step 3 "time levels" [[sources/pdf-930894c4fbad]] [[sources/pdf-94cecf7a170a]] [[sources/pdf-1ab14c833d75]].
- Relies heavily on terminology originated by Michael J. Huddleston (ICT) — order block, fair value gap, AMD cycle, MMxM — and provides applied trade plans (HIPPO, OSOK, GB-OB, GB-Breaker, GB-stop-run, GB-equilibrium, GB-FVG) within that vocabulary [[sources/pdf-930894c4fbad]] [[sources/pdf-94cecf7a170a]]; Version 1.1.3 adds the GB-Einstein plan to the family [[sources/pdf-1ab14c833d75]].
- Demonstrates the framework on a Microsoft chart with PO3 27-point partitions (0–27, 27–54, 54–81, ...) to show how price stays inside a partition before transitioning to the next [[sources/pdf-930894c4fbad]] [[sources/pdf-94cecf7a170a]] [[sources/pdf-1ab14c833d75]].
- Uses "a tweaked version" of the Tesla Vortex for longer-term Weekly and Daily views — the timeframes ICT identifies as where banks trade — and integrates the resulting algorithm into a "Putting it all together" workflow with the Market Maker Sell Model and Optimal Trade Entry [[sources/pdf-930894c4fbad]] [[sources/pdf-94cecf7a170a]] [[sources/pdf-1ab14c833d75]].
- Operates an associated Discord community, an affiliate program (framed in Version 1.0.9 as a way to fight fraudulent copies), and offers Purchasing Power Parity pricing for the book [[sources/pdf-930894c4fbad]] [[sources/pdf-94cecf7a170a]] [[sources/pdf-1ab14c833d75]].
