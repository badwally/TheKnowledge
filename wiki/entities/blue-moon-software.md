# Blue Moon Software

## Summary

Blue Moon Software is an attorney-reviewed rental-document provider that integrates with [[entities/tenanttech]] to deliver rental applications and lease forms in regions where TenantTech customers do not have direct access to such documents [[sources/web-2025-11-17-cf4]].

## Key facts

- Blue Moon Software provides attorney-reviewed rental applications and lease forms [[sources/web-2025-11-17-cf4]].
- At OpTech 2025 (Nov 17, 2025), [[entities/inhabit]] announced the [[entities/tenanttech]] Blue Moon integration, giving TenantTech customers optional access to Blue Moon documents in regions previously underserved by TenantTech's native attorney-reviewed inventory [[sources/web-2025-11-17-cf4]].
- Blue Moon Software is positioned as a rental-housing legal-document provider; the Nov 2025 integration scope is multifamily rental only, with no condo/HOA governance-document equivalent announced [[sources/web-2025-11-17-cf4]].
