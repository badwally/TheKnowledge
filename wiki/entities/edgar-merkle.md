# Edgar Merkle

## Summary

Edgar Merkle is a statistician and a co-author with Sophia Rabe-Hesketh on work applying predictive information criteria to hierarchical Bayesian models. He implemented marginal-likelihood evaluation for these criteria in the R package blavaan, which leverages lavaan for structural equation modelling.

## Key facts

- Merkle is referenced by the speaker as a co-author who implemented marginal-likelihood evaluation in the R package blavaan, which exploits lavaan for structural equation modelling, to evaluate the marginal likelihood for given draws of the parameters [[sources/yt-WJ1BvfOm-94]].
- Merkle's blavaan implementation supports marginal versions of DIC for structural equation models, which are not typically available in standard Bayesian software [[sources/yt-WJ1BvfOm-94]].
