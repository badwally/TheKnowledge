# Ryan Jessop

## Summary

Ryan Jessop is a Project Manager at Charles Taylor and the named testimonial author featured in HomeRun IQ's published customer testimonials, attributing a 30–40% fee impact to the templating features baked into the HomeRun IQ platform [[sources/web-2026-01-01-936]].

## Key facts

- Title: Project Manager at Charles Taylor [[sources/web-2026-01-01-936]].
- Named as the source of the Charles Taylor testimonial published in HomeRun IQ's features-page customer-quote section [[sources/web-2026-01-01-936]].
- Attributed quotation: "We've been able to address and affect our fee by 30 to 40% because of all of the templating type features that are already baked into HomeRun IQ." [[sources/web-2026-01-01-936]]
- Frames the fee impact as a function of platform-native templating features rather than firm-side customization effort [[sources/web-2026-01-01-936]].
