# Freddie Mac Form 1077 (Condominium Project Questionnaire)

## Summary

Freddie Mac Form 1077 is the Freddie Mac counterpart to Fannie Mae Form 1076 — the Condominium Project Questionnaire required for every conventional mortgage on a condominium unit [[sources/web-2026-02-11-4eb]]. In CommunityPay's product framing, Form 1077 is consistently named in parallel with Form 1076 as covered by the same Condo Questionnaire API auto-fill workflow [[sources/web-2026-02-11-4eb]].

## Key facts

- Issued by Freddie Mac as the GSE counterpart to Fannie Mae Form 1076 [[sources/web-2026-02-11-4eb]].
- Every conventional mortgage for a condo unit requires a completed Form 1076 (Fannie Mae) or Form 1077 (Freddie Mac) [[sources/web-2026-02-11-4eb]].
- Named in parallel with Form 1076 in CommunityPay's Condo Questionnaire API documentation as covered by the same auto-fill workflow [[sources/web-2026-02-11-4eb]].
