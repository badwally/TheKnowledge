# SHELF R Package

## Summary

The SHELF R package is the software component of the Sheffield Elicitation Framework, distributed on CRAN to support elicitation of probability distributions from experts.

## Key facts

- The SHELF R package is the software component of the Sheffield Elicitation Framework distribution, available on the Comprehensive R Archive Network (CRAN) [[sources/web-2026-05-13-b67]].
- Version 1.13.0 of the SHELF R package was published on CRAN in April 2026, with a full list of updates available on its CRAN news page [[sources/web-2026-05-13-b67]].
