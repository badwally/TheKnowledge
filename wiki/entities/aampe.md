# Aampe

## Summary

Aampe is an agentic AI infrastructure platform for cross-channel customer messaging that uses AI agents and reinforcement learning to deliver 1:1 personalized experiences across email, push, mobile push, and SMS [[sources/web-2025-02-03-42a]]. It positions in the "AI Decisioning" category for CRM and lifecycle marketers and is a direct competitive-set entry for Orita's audience-intelligence layer [[sources/web-2025-02-03-42a]].

## Key facts

- Founded in 2020 by Paul Meinshausen, Schaun Wheeler, and Sami Abboud [[sources/web-2025-02-03-42a]].
- Replaces traditional A/B testing and rule-based personalization with multi-armed bandits and AI agents that run thousands of multivariate tests simultaneously across the customer base [[sources/web-2025-02-03-42a]].
- Not warehouse-native: first-party data must be ingested from an external source such as a customer data platform, after which Aampe stores and uses it [[sources/web-2025-02-03-42a]].
- Content model requires operators to break each message into components (e.g. Greeting, Offer, Value Prop) and tag each component with semantic attributes (e.g. CTA=urgency, tone=playfulness) [[sources/web-2025-02-03-42a]].
- Delivery options include triggering messages through the customer's existing platforms or calling Aampe's API to retrieve content at send time [[sources/web-2025-02-03-42a]].
- Supports operator-defined guardrails such as daily message caps and quiet hours, plus dashboards for channel and content performance analytics [[sources/web-2025-02-03-42a]].
- Channel coverage spans email, push, in-app, SMS, WhatsApp, and banners; the system selects channel per user based on observed behavior [[sources/web-2025-02-03-42a]].
- Use cases include email-powered cross-sell recommendations, repeat-purchase offer testing, onboarding drop-off re-engagement, and feature-adoption nudges [[sources/web-2025-02-03-42a]].
- Hightouch identifies Aampe as a peer AI Decisioning vendor alongside Movable Ink and OfferFit, while contrasting Hightouch's warehouse-native architecture against Aampe's non-warehouse-native ingest model [[sources/web-2025-02-03-42a]].
