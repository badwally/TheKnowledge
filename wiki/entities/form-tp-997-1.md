# Form TP-997.1 — Information Return for Tax-Exempt Entities (Quebec)

## Summary

Form TP-997.1 is the Revenu Québec Information Return for Tax-Exempt Entities, which some Québec tax-exempt entities may need to file in addition to the CO-17.SP depending on their activities and assessment category [[sources/web-2025-11-06-d1c]]. The form is a parallel disclosure instrument for tax-exempt entities that supplements (but does not replace) the CO-17.SP NPO information return that most condominium syndicates must file [[sources/web-2025-11-06-d1c]].

## Key facts

- Issued by Revenu Québec [[sources/web-2025-11-06-d1c]].
- Officially titled "Information Return for Tax-Exempt Entities" [[sources/web-2025-11-06-d1c]].
- Some Québec tax-exempt entities may be required to file the TP-997.1 depending on their activities and assessment category [[sources/web-2025-11-06-d1c]].
- T2inc.ca recommends consulting a CPA accountant or tax professional familiar with non-profit taxation in Québec when uncertain about TP-997.1 applicability [[sources/web-2025-11-06-d1c]].
