# SRAM eTap AXS

## Summary

SRAM eTap AXS is the wireless electronic road-cycling groupset from [[entities/sram|SRAM]] — a complete drivetrain and braking system spanning shifters, derailleurs, crankset, cassette, batteries, and disc or rim brakes, with all components pairing wirelessly and configurable through the [[entities/sram-axs-app|SRAM AXS App]] [[sources/pdf-f13aa755f8e2]].

## Key facts

- Recorded as "ETAP AXS" on the Studio Velo work order for the Parlee Z-Zero XD custom-geometry frame [[sources/pdf-95753e942ede]].
- Bundled into the Z-Zero XD's $15,708.00 frame-and-build line item at Studio Velo in August 2019 [[sources/pdf-95753e942ede]].
- A product line from SRAM, LLC — the same manufacturer behind hydraulic road disc brakes such as [[entities/sram-hrd|HRD]] [[sources/pdf-b51938faf250]].
- Documented end-to-end by SRAM's eTap AXS Systems User Manual, 95-7918-013-000 Rev J (© 2021 SRAM, LLC) — described as a complete system installation guide "from unboxing each component to heading out for a ride" [[sources/pdf-f13aa755f8e2]].
- AXS components are only compatible with other AXS components; SRAM publishes a separate AXS Components Compatibility Map as the canonical cross-component reference [[sources/pdf-f13aa755f8e2]].
- The system's components must be wirelessly paired together — [[concepts/axs-system-pairing|System Pairing]] is its own discrete step in the install procedure, between AXS Button setup and the first ride [[sources/pdf-f13aa755f8e2]].
- Powered by removable, rechargeable SRAM batteries, with dedicated charging and installation procedures in the manual [[sources/pdf-f13aa755f8e2]].
- Each shifter carries a dedicated [[concepts/axs-button|AXS Button]] whose function is configurable separately from the standard shift paddle [[sources/pdf-f13aa755f8e2]].
- Supports a default shift mode plus an alternative [[concepts/enhanced-shifting|Enhanced Shifting]] mode that changes how shifts are coordinated [[sources/pdf-f13aa755f8e2]].
- Integrates with e-Bike/Pedelec systems and exposes a [[concepts/multi-shift|multi-shift]] capability in that context [[sources/pdf-f13aa755f8e2]].
- The optional [[entities/sram-axs-blipbox|eTap AXS BlipBox]] is the supported "Aero Option" for using the system on aerobar handlebars where standard road shifters do not fit [[sources/pdf-f13aa755f8e2]].
- Available in both disc-brake and rim-brake variants — the manual documents Rim Brake Caliper Installation alongside Disc Brake Caliper Installation, 6-bolt and Center Lock rotor mounting, hose shortening and bleed, and a [[concepts/brake-bed-in|bed-in procedure]] for new pads/rotors [[sources/pdf-f13aa755f8e2]].
- Front-derailleur setup uses a dedicated Set Up Tool, with separate procedures documented for braze-on and clamp-mount frames [[sources/pdf-f13aa755f8e2]].
