# PHM Society Data Repository

## Summary

The PHM Society Data Repository is a public collection of free, downloadable datasets hosted by the PHM Society at data.phmsociety.org, supporting prognostics and health management research.

## Key facts

- The PHM Society Data Repository is hosted at data.phmsociety.org/phm-datasets/ [[sources/web-2023-01-05-939]].
- The repository makes several free downloadable datasets available [[sources/web-2023-01-05-939]].
- The repository page links to the NASA Prognostics Center of Excellence Dataset Repository as a related dataset source [[sources/web-2023-01-05-939]].
