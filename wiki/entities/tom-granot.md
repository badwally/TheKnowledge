# Tom Granot

## Summary

Tom Granot is the creator of the **SyntaxGTM** YouTube channel, focused on go-to-market tooling for developer-minded operators, and the author of an open-source repository of HubSpot admin skills for Claude Code [[sources/yt-ZUIprPSbYO4]].

## Key facts

- Runs the **SyntaxGTM** channel on YouTube at `https://www.youtube.com/@SyntaxGTM` [[sources/yt-ZUIprPSbYO4]].
- Self-describes as primarily a PMM (product marketing manager) by role but a developer by background, which led him to treat HubSpot administration as a scripting problem rather than a UI problem [[sources/yt-ZUIprPSbYO4]].
- Author of the **HubSpot admin skills** repository — a Claude Code skill bundle covering audit, implementation planning, data hygiene, enrichment, ICP tiering, lead scoring, automation workflows, and ongoing property maintenance [[sources/yt-ZUIprPSbYO4]].
- Has worked in startup environments long enough that HubSpot became "second nature" — frames his own work as bringing developer ergonomics (scripts, retry logic, atomic operations with rollback) to CRM admin [[sources/yt-ZUIprPSbYO4]].
- Uses a task-management system as the orchestration spine for CRM mutations: one ticket per skill run, with status comments at each of plan, before, execute, and after stages [[sources/yt-ZUIprPSbYO4]].
