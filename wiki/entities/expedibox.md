# Expedibox

## Summary

Expedibox is a parcel locker vendor integrated with UpperBee Condo and UpperBee Rental as one of three named smart-locker partners in the UpperBee integration portfolio [[sources/web-2025-01-31-f4e]]. The Expedibox + UpperBee combination is positioned as a turnkey solution for efficient package management with real-time package delivery [[sources/web-2025-01-31-f4e]].

## Key facts

- Parcel locker vendor integrated with both UpperBee Condo and UpperBee Rental [[sources/web-2025-01-31-f4e]].
- Positioned to support real-time package delivery [[sources/web-2025-01-31-f4e]].
- Marketed as a turnkey solution for efficient package management when combined with UpperBee [[sources/web-2025-01-31-f4e]].
- One of three named smart-locker partners in UpperBee's integration portfolio alongside Snaile Lockers and BlueBox [[sources/web-2025-01-31-f4e]].
- Public-facing site: expedibox.com [[sources/web-2025-01-31-f4e]].
