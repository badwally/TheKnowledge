# FSRConnect (Connect)

## Summary

FSRConnect — branded as "Connect" in BuildingLink integration copy — is a CAM accounting platform named as one of 17 accounting integration partners in BuildingLink's resident-engagement platform [[sources/web-2022-01-01-3fa]]. The FSRConnect–BuildingLink integration is distinctive among BuildingLink's accounting partners in two ways: it supports an optional reverse-sync of resident contact-information changes from BuildingLink back into Connect, and it allows the Connect document library to be framed within BuildingLink as an embedded resource [[sources/web-2022-01-01-3fa]].

## Key facts

- Named as an accounting integration partner in BuildingLink's accounting-integration catalog under the heading "FSRConnect" with body copy referring to the product as "Connect" [[sources/web-2022-01-01-3fa]].
- Syncs with BuildingLink every 24 hours to update resident move-in/move-out information [[sources/web-2022-01-01-3fa]].
- Supports an optional reverse-sync setting: contact-information changes made by residents in BuildingLink can be pushed back into Connect [[sources/web-2022-01-01-3fa]].
- The integration allows unit owners to view account information (balance + transaction history) on the BuildingLink resident site [[sources/web-2022-01-01-3fa]].
- The Connect document library can be framed within BuildingLink as an embedded view [[sources/web-2022-01-01-3fa]].
- Reverse-sync and document-library framing are optional settings that can be configured to each property's preferences [[sources/web-2022-01-01-3fa]].
