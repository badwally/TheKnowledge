# Condo Manager

## Summary

Condo Manager is a CAM accounting software vendor named as one of 17 accounting integration partners in BuildingLink's resident-engagement platform [[sources/web-2022-01-01-3fa]]. The Condo Manager–BuildingLink integration allows Condo Manager account information — balance and transaction history — to be surfaced to unit owners on the BuildingLink resident site [[sources/web-2022-01-01-3fa]].

## Key facts

- Named as an accounting integration partner in BuildingLink's accounting-integration catalog [[sources/web-2022-01-01-3fa]].
- The integration syncs Condo Manager account information into BuildingLink [[sources/web-2022-01-01-3fa]].
- Unit owners can view their Condo Manager account balance and transaction history on the BuildingLink resident site [[sources/web-2022-01-01-3fa]].
