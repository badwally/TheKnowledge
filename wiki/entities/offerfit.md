# OfferFit

## Summary

OfferFit is an AI decisioning platform that acts as a decision layer between the customer's data systems and downstream marketing tools, using reinforcement learning to move beyond traditional A/B testing toward individual-customer personalization [[sources/web-2025-02-03-42a]].

## Key facts

- Architecturally positioned as an intermediate decision layer between source data systems and marketing-tool execution [[sources/web-2025-02-03-42a]].
- Uses reinforcement learning to personalize at the individual customer level, replacing traditional A/B testing [[sources/web-2025-02-03-42a]].
- Hightouch characterizes OfferFit as a managed service with a "black box" feel: applying new use cases typically requires external support, which Hightouch frames as a constraint on experimentation velocity and agility [[sources/web-2025-02-03-42a]].
- Named by Hightouch as a peer AI Decisioning vendor in the same competitive set as Aampe and Movable Ink [[sources/web-2025-02-03-42a]].
