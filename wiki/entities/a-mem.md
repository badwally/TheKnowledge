# A-Mem

## Summary

A memory-based agent system referenced by Hu et al. (2026) as an example of existing agentic memory implementations whose query latency degrades sharply with memory size — motivating the Pancake multi-tier design [[sources/pdf-zhengding-hu-2026-pancake-hierarchical-memory]].

## Key facts

- Cited by Hu et al. (2026) alongside Mem-GPT as a representative memory-based agent that ships its own memory implementation [[sources/pdf-zhengding-hu-2026-pancake-hierarchical-memory]].
- Characterized as emphasizing functionality over performance, with suboptimal indexing and searching implementations whose query latency reaches more than 99% of end-to-end runtime at scale [[sources/pdf-zhengding-hu-2026-pancake-hierarchical-memory]].
