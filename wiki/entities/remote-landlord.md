# Remote Landlord

## Summary

Remote Landlord is a property-management software vendor named as one of 17 accounting integration partners in BuildingLink's resident-engagement platform [[sources/web-2022-01-01-3fa]]. The Remote Landlord–BuildingLink integration runs on a 24-hour batch sync that propagates resident information from Remote Landlord into BuildingLink, eliminating manual dual-platform resident maintenance [[sources/web-2022-01-01-3fa]].

## Key facts

- Named as an accounting integration partner in BuildingLink's accounting-integration catalog [[sources/web-2022-01-01-3fa]].
- Syncs with BuildingLink every 24 hours [[sources/web-2022-01-01-3fa]].
- The integration eliminates the need for staff to add or remove residents on both platforms manually, easing data-management workload on property staff [[sources/web-2022-01-01-3fa]].
