# Schwalbe G-One Speed

## Summary

The Schwalbe G-One Speed is a tubeless-ready gravel/road tire from [[entities/schwalbe|Schwalbe]] sold by [[entities/studio-velo|Studio Velo]] in a 700 x 30c folding-bead variant in September 2019 [[sources/pdf-a5ea98378b0a]].

## Key facts

- Sold in a 700 x 30c folding-bead variant at Studio Velo for $80.00 in September 2019 [[sources/pdf-a5ea98378b0a]].
- Built on Schwalbe's Evolution Line platform [[sources/pdf-a5ea98378b0a]].
- Uses the OneStar Compound rubber [[sources/pdf-a5ea98378b0a]].
- Casing combines MicroSkin protection with V-Guard puncture protection [[sources/pdf-a5ea98378b0a]].
- Marketed as "Tubeless Easy" — i.e., designed for straightforward tubeless setup [[sources/pdf-a5ea98378b0a]].
- Sold in black [[sources/pdf-a5ea98378b0a]].
