# Claude Code

## Summary

Claude Code is Anthropic's agentic coding harness, used by Orita's CMO as the runtime for building company-wide skills and agents [[sources/pdf-4931157e130a]]. Orita's internal stack explicitly pairs Claude Code with MCP integrations as the substrate for replacing manual marketing workflows [[sources/docx-25c1bcf28fb8]].

## Key facts

- Used as the runtime for company-wide skills and agents at Orita [[sources/pdf-4931157e130a]].
- Paired with MCP integrations (HubSpot, Gmail, Google Calendar, Slack) as the standard tool-access pattern for workflow agents [[sources/docx-25c1bcf28fb8]].
- Existing event attendee list enrichment skill is the reference implementation demonstrating the Claude Code + external API pattern at Orita [[sources/docx-25c1bcf28fb8]].
- Designated as the CMO's natural-language interface (alongside Cowork) for interacting with the planned agent hierarchy [[sources/docx-25c1bcf28fb8]].
