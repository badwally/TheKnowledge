# Yardi Voyager 7S

## Summary

Yardi Voyager 7S is the Yardi product designation required for compatibility with the Condo Control integration, per Condo Control's published integration documentation [[sources/web-2026-05-24-c93]]. Compatibility additionally requires that the Voyager 7S installation expose Interfaces at minimum version PIv14.3, with the Billing & Payments Interface at minimum PIv7 and the Common Data Interface at minimum PIv14.1, and that the Yardi property type be set to "Condo" or "Residential" rather than "Commercial" [[sources/web-2026-05-24-c93]].

## Key facts

- The named Yardi product designation supported by the Condo Control integration is "Voyager 7S" [[sources/web-2026-05-24-c93]].
- Voyager 7S compatibility with the Condo Control integration requires Interfaces at minimum version PIv14.3 [[sources/web-2026-05-24-c93]].
- The Billing & Payments Interface on a compatible Voyager 7S installation must be at minimum version PIv7 [[sources/web-2026-05-24-c93]].
- The Common Data Interface on a compatible Voyager 7S installation must be at minimum version PIv14.1 [[sources/web-2026-05-24-c93]].
- The Yardi property type on a compatible Voyager 7S installation must be "Condo" or "Residential" [[sources/web-2026-05-24-c93]].
- Yardi property type "Commercial" is not currently supported by the Condo Control integration on Voyager 7S [[sources/web-2026-05-24-c93]].
