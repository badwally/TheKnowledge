# SRAM eTap AXS BlipBox

## Summary

The eTap AXS BlipBox is the [[entities/sram|SRAM]]-supplied "Aero Option" for the [[entities/sram-etap-axs|eTap AXS]] groupset — a separately-installed module that brings AXS shifting to aerobar handlebars where the standard road shifters do not fit [[sources/pdf-f13aa755f8e2]].

## Key facts

- Documented in the eTap AXS Systems User Manual as the "eTap AXS BlipBox - Aero Option," sitting alongside the standard shifter install procedures rather than replacing them [[sources/pdf-f13aa755f8e2]].
- Marketed across SRAM's nine-language documentation under the same BlipBox name with localised "Aero Option" subtitles (Aero-Option / Opzione Aero / Aero Optie / Opção Aero / Aero のオプション / Aero 选项) [[sources/pdf-f13aa755f8e2]].
