# SRAM AXS App

## Summary

The SRAM AXS App is the companion mobile app from [[entities/sram|SRAM]] used to configure [[entities/sram-etap-axs|eTap AXS]] groupsets — covering [[concepts/axs-system-pairing|system pairing]], [[concepts/axs-button|AXS Button]] function assignment, and selection of shift modes such as [[concepts/enhanced-shifting|Enhanced Shifting]] [[sources/pdf-f13aa755f8e2]].

## Key facts

- The eTap AXS Systems User Manual gives the SRAM AXS App its own dedicated section in the install flow, placed between Tools and Supplies inventory and SRAM Battery Charging — i.e., it is a prerequisite, not an optional polish step [[sources/pdf-f13aa755f8e2]].
- Translated and published across SRAM's nine-language documentation under consistent localised names — "SRAM AXS App / Application SRAM AXS / Aplicación SRAM AXS / SRAM AXS アプリ / SRAM AXS 应用程序" [[sources/pdf-f13aa755f8e2]].
