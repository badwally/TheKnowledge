Baseline Diagnostic Test for Graduate-Level Statistics Training
Section 1: Mathematics (Fundamental Concepts for Statistics)
1. Calculus Review
- Compute the derivative of f(x) = 3x^2 - 4x + 7. Explain its real-world application.
- Evaluate the definite integral of (3x^2 - 4x + 7) from x=0 to x=1 and interpret the result.
- Find the partial derivative of f(x, y) = x^2y + 3xy^2 with respect to x.
2. Linear Algebra
- Given the matrix A = [[2, 1], [3, 4]], compute its determinant and explain its meaning.
- Solve for x in the system of equations: 2x + y = 5 and 3x + 4y = 10.
- How could eigenvalues/eigenvectors be used to reduce risk in a financial portfolio?
3. Probability & Distributions
- A stock has a 50% chance of increasing by 10% and a 50% chance of decreasing by 5%. What
is the expected return?
- If daily stock returns follow a normal distribution (mean=0.5%, std dev=1%), what is the
probability of exceeding 2%?
- Explain the Central Limit Theorem and its relevance to financial market analysis.
Section 2: Statistics & Market Applications
4. Descriptive Statistics
- Given stock closing prices [100, 102, 101, 103, 105], compute:
- Mean return (assuming log returns).
- Standard deviation of returns.
- Sharpe ratio (risk-free rate = 0.1%).
5. Regression & Correlation
- If Apple stock returns correlate with the Nasdaq index, how do you determine if this correlation is
causal or spurious?
- Given the regression R_AAPL = alpha + beta * R_NASDAQ + epsilon:
- Explain the significance of beta.
- How would you test if beta is significantly different from 1?
6. Hypothesis Testing
- A trader claims that a strategy produces excess returns.
- Formulate null and alternative hypotheses to test this claim.
- Describe how to conduct a t-test using historical data.

Section 3: Programming & Data Analysis Readiness
7. Python Basics
- Write a function to compute the mean and standard deviation of a list of numbers.
- Write a function to compute daily log returns of stock prices.
8. R Basics
- Load a dataset containing stock prices and compute the moving average.
- Write an R script to generate a histogram of stock returns.
9. Market Data Handling
- Given stock price data in a CSV file, how would you:
- Load the data into a Pandas DataFrame (Python) or a Tibble (R)?
- Compute the 5-day rolling standard deviation of returns?
