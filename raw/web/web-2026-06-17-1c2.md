## Abstract:

To improve the accuracy and generation efficiency of converting natural language to the graph database query language Cypher, this paper proposes a lightweight architecture that requires no fine-tuning and no prompt engineering. This method achieves performance optimization with the aid of a system-level strategy module without modifying the pre-trained large language model.Specifically, we designed two core components: Schema Filtering and Candidate Generation. The former filters schema information highly related to the input question through a dynamic pruning mechanism to reduce redundancy interference; the latter uses LLM to generate multiple semantically diverse query candidates to improve semantic hit rate and fault tolerance.This architecture has good scalability and deployment convenience.Experimental results show that the method in this paper significantly outperforms existing baseline models on multiple evaluation metrics such as Pass{@}1, Pass{@}3, and Jaccard, which verifies its effectiveness and versatility in the Text2Cypher task.
