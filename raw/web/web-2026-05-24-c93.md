Condo Control utilizes the following Yardi Interfaces to import/export data between Condo Control and Yardi:

**Billing and Payments Interface**- Used for financial data and retrieving Unit information as well as Condo Owner Type such as Renter/Owner based on the T-code.**Common Data Interface**- Used for retrieving Resident information and Alternate Addresses.


Condo Control uses the “GetCondoUnitInformation_Login” API endpoint from the Billing and Payments Interface, which returns Condo Control a list of Unit Numbers, Addresses and Resident T-codes. From there, we use the "GetResidentData" API endpoint from the Common Data interface, passing in T-codes from the "GetCondoUnitInformation_Login" API call to get Resident Names, Emails, Phone Numbers, Alternate Addresses, and Roommates (R-codes). Condo Control then parses this information and imports it into Condo Control.


This means for a Yardi Property to be compatible with the Condo Control integration, it must meet the following criteria:

- Yardi product is "Voyager 7S" with Interfaces minimum version PIv14.3
- Billing & Payments Interface minimum version PIv7.
- Common Data Interface minimum version PIv14.1.

- Yardi property type is "Condo" or "Residential".

The Condo Control integration does not currently support the following criteria:

- Yardi property type of "Commercial".


If you are unable to determine if your Yardi property is compatible with Condo Control, open a Support Ticket with Yardi and provide them with the above information. They should be able to determine compatibility with Condo Control.
