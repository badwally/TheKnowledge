## Abstract:

Natural language query generation for complex graph-structured data faces challenges in domain-specific settings. Existing large language Mmdels (LLMs) often suffer from logical gaps when handling complex relational queries. To address these issues, this paper proposes a Code-Collaborative Intelligent Query Generation Framework. The framework leverages the sensitivity of Code LLMs to formal logic to parse complex topological dependencies. First, the study introduces a Dual-View Graph Representation mechanism. This mechanism constructs an object-oriented code view alongside a lightweight dictionary view. It transforms graph schema constraints into type-checking logic executable by the model, thereby mitigating structural hallucinations. Second, the paper designs a Structured Logic Planning (SLP) protocol. This protocol decouples unstructured natural language into explicit reasoning steps: path determination, semantic extraction, and schema mapping. The research further employs LoRA to fine-tune the DeepSeek-Coder backbone, enabling the model to internalize the structured reasoning paradigm. Experimental results on the constructed CRD-Instruct dataset demonstrate the superiority of the method. The model achieves a ROUGE-L score of 69.86%. It outperforms the untuned general baseline by approximately 27%. These results validate the accuracy and robustness of the approach in complex Text-to-Cypher generation tasks.

### I. Introduction

Large language models (LLMs) have demonstrated strong capabilities in semantic understanding and text generation. However, as probabilistic generative models, they still struggle with tasks requiring strict logical consistency and factual precision, often exhibiting hallucinations and unstable reasoning \[1\]. A promising direction to mitigate these issues is to integrate LLMs with structured data, where explicit relational information can enhance reasoning reliability \[2\], \[3\]. In structured querying scenarios such as knowledge graph question answering, this requires translating natural language into executable queries over structured schemas.
