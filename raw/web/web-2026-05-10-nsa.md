# Nova Scotia Open Data - Active Condominium Corporations

**Source.** Service Nova Scotia, Registrar of Condominiums (via the provincial open-data portal at `data.novascotia.ca`).

**Canonical landing pages:**
- Visualization chart asset: <https://data.novascotia.ca/Permits-and-Licensing/Active-Condominium-Corporations-Total-Number-of-Un/9w9g-2c83> (asset id `9w9g-2c83`).
- Underlying tabular dataset (poly layer): <https://data.novascotia.ca/Permits-and-Licensing/Active-Condominium-Corporations-Poly-Layer-/eq9a-ayyh> (asset id `eq9a-ayyh`).

**License.** Open Government Licence - Nova Scotia (`OGL_NOVA_SCOTIA`). Freely usable, modifiable, and redistributable under attribution to the Province of Nova Scotia / Service Nova Scotia.

**Publication.** Created 2015-12-11; published 2023-07-26; rows last updated 2026-05-05. Maintained by Service Nova Scotia, Registrar of Condominiums.

**Description (provincial).** 'Provincial listing of Active Condominium Corporation in Nova Scotia by County.' The dataset enumerates every Condominium Corporation currently active on the Registrar's register, with corporation number, phase, community, declarant, unit-count breakdown by unit type, and geospatial polygon for the registered footprint.

**Citation.** Service Nova Scotia, Registrar of Condominiums. *Active Condominium Corporations (Poly Layer)*. Open dataset on `data.novascotia.ca`, asset id `eq9a-ayyh`. Retrieved via Socrata API on 2026-05-10.

## Schema

Each row is one Condominium Corporation phase. Columns:

| Column | Description |
|--------|-------------|
| `county` | Nova Scotia county of registration. |
| `number` | Condominium Corporation registration number assigned by the Registrar of Condominiums. |
| `phase_if_applicable` | Phase number for phased developments. |
| `community` | Municipal community (sub-municipal locality). |
| `declarant` | Legal name of the corporation's declarant of record. |
| `residential_units` | Count of residential dwelling units in the phase. |
| `commercial_units` | Count of commercial units. |
| `recreational_units` | Count of recreational units. |
| `parking_units` | Count of parking units registered as separate condominium units. |
| `storage` | Count of storage units registered as separate condominium units. |
| `bare_land_residential` | Count of residential units in a bare-land condominium configuration. |
| `bare_land_commercial` | Count of commercial bare-land units. |
| `total_units` | Sum of unit counts for the phase. |
| `pid` | Property Identifier from the NS Parcel Identification system. |
| `pid_corp` | Composite identifier `<pid>_<corp number>`. |
| `nsprd_s_id` | NS Property Records Database segment id. |
| `nsprd_mu` | NS Property Records Database municipal id. |
| `nsprd_date` | Date the polygon was last refreshed from the NS Property Records Database. |
| `the_geom` | MultiPolygon WKT geometry in WGS84 of the registered footprint. |

## Provincial totals (snapshot fetched 2026-05-10)

The full poly-layer pull on 2026-05-10 returned **526 active corporation phases** spanning **13 counties**, accounting for **16,949 residential units** and **20,572 total units** across all unit types.

Halifax County is the dominant share: 80.8% of phases (425/526) and 88.8% of total units (18,263/20,572). Halifax + Lunenburg together account for 88.0% of phases and 91.9% of units. Outside the South Shore + HRM corridor, no NS county exceeds 11 active corporation phases.

The reported total of 526 *phases* corresponds to fewer unique *corporations* - phased developments register each phase separately under one Corporation number. The Cox & Palmer figure of '400+ NS corporations represented' cited in `regulatory/ns-condominium-act-summary.md` is consistent with the 526-phase count assuming a phase-to-corporation ratio of roughly 1.1-1.3.

## Material content for capital-infrastructure forecasting

1. **Market frame.** The dataset closes Brief-0006's first open question (exact NS condo-corporation count and HRM share). The NS Year-1 acquisition universe is roughly 425 Halifax-County phases.
2. **Unit-mix decomposition.** 82.4% of all registered units are residential; the residential / commercial / parking-as-separate-unit split is now directly observable.
3. **Declarant concentration.** The `declarant` column is the primary lever for understanding developer concentration - a small number of declarants repeat across many corporations. This is the structural basis for the management-firm channel cited in Brief-0006 section 2.1 and for Brief-0004 Phase-5 referral expansion.
4. **Geospatial overlay.** The `the_geom` MultiPolygon geometry enables direct cross-validation against HRM open-data building permits and Statistics Canada census condo-dwelling tables.
5. **Layer-2 market sizing.** The denominator lets us quote the design-partner case study against an explicitly bounded market: 'case study from one Halifax 100-unit building, of an active NS market of ~425 corporations with 16,949 residential units.'

## Coverage and gaps

- **No reserve-fund-study data in this dataset.** Completed 5-year reserve-fund studies are corporation records, not Registrar filings. The Registrar's public dataset surfaces metadata only.
- **No funding-adequacy fields.** Reserve-fund balance, contribution rate, and study cadence are not present. Those covariates flow through Brief-0004's bilateral LOI pull.
- **Phased developments require deduplication.** A `(number, phase_if_applicable)` composite key uniquely identifies a registered phase; deduplicating to `number` gives the corporation count.
- **Geospatial-only ground truth.** The poly layer is the only `data.novascotia.ca` resource that exposes the underlying tabular data. The named asset `9w9g-2c83` ('Total Number of Units by County') is a visualization chart built on top of the poly layer; fetching it via HTTP returns navigation chrome only because the rendering is JS-mediated. Programmatic access is via the Socrata REST API (`/resource/eq9a-ayyh.csv`).
