## Deliverable

TOOL-16: `wiki question new` and `wiki question list` — management CLI for the question page type introduced in M92 (ONT-14).

## Implementation

**`src/gateway/ops/question.py`** (new)
- `question_new(slug, title, domain, status="open") -> OperationResult`: validates slug + status, creates `wiki/questions/<slug>.md` with correct frontmatter (`type`, `slug`, `title`, `domains`, `status`, `created_at`, `last_updated`) and stub body (`## Question` + `## Context`); errors if page already exists
- `question_list(domain=None, status=None) -> list[dict]`: walks wiki pages via `walk_wiki_pages()`, filters by `page_type == "question"`, optionally by domain and status; sorts by `(status, last_updated)`

**`src/gateway/cli.py`**
- Added `"question"` to SUBCOMMANDS and IMPLEMENTED
- Added `p_question` parser with `new` and `list` sub-subcommands
- `new`: positional `slug` + `title`, `--domain` (required), `--status` (default: open)
- `list`: optional `--domain`, `--status`, `--json` for machine-readable output
- Added `_run_question_cmd(ns)` dispatcher
- Added `"question"` to CLI_ONLY in `mcp_server.py` (umbrella; fine-grained MCP tools registered as auxiliaries)

**`src/gateway/mcp_server.py`**
