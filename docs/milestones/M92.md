## Deliverable

ONT-14: `question` page type at `wiki/questions/<slug>.md`. Aggregates the
"Open questions" items scattered across MOCs and synthesis pages into first-class
addressable pages with lifecycle tracking (`status: open|partial|answered`).

## Implementation

**`src/gateway/wiki_pages.py`**
- `question` entry in `PAGE_SCHEMAS`: directory `wiki/questions/`, required fields
  `type slug title domains status created_at last_updated`, required sections
  `Question Context`, `citation_grounded=False`

**`src/gateway/validator.py`**
- `QUESTION_STATUS_ENUM = {"open", "partial", "answered"}`
- `validate_question_frontmatter(front)`:
  - ERROR `question-status-unknown` for invalid status
  - WARNING `question-answered-missing-synthesis` for answered pages without `synthesis:` link
- Wired into `validate_wiki_page()` when `page_type == "question"`

**`src/gateway/lint/unanswered_questions.py`**
- `run_open_questions()`: INFO finding per open/partial question
- `run_answered_no_synthesis()`: WARNING per answered question with no `synthesis:` link

**`src/gateway/ops/lint.py`**
- Registered `open-questions` + `answered-no-synthesis` checks
