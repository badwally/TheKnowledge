# M47 — K5 token telemetry + K2 MCP-CLI parity (Wave 1)

**Date:** 2026-05-24
**Branch:** `wave-1/k5-k2`
**Plan:** `docs/plans/2026-05-24-k1-k5-keystones.md`
**Decision transcript:** `docs/plans/2026-05-24-k1-k5-keystones-decisions.md`

Wave 1 of the K1–K5 keystone implementation. K5 (telemetry) and K2 (MCP-CLI
parity) ship together as the foundation; Wave 2 (K1 edit-path + K4 scheduler
+ K3 cloud shim) builds on it.

## What shipped

### K5 — Token telemetry

- **New `CallResult` dataclass** at `src/gateway/llm/telemetry.py` capturing
  text, input/output/cache tokens, model, stop reason, duration_ms,
  total_cost_usd. Parsed from `claude -p --output-format json` envelopes.
- **New `call_with_usage()` method** on `ClaudeCLIClient` (siblings:
  `call_with_usage` on `ClaudeCLIFilterClient`, `ClaudeCLIPlanClient`,
  `describe`-with-telemetry on `ClaudeCLIVLMClient`). Existing `call()`
  returning plain text preserved for back-compat per D7.
- **New per-model pricing table** at `src/gateway/costs.py` (Opus 4.7,
  Sonnet 4.6, Haiku 4.5) with `estimate_cost()`. Used by `wiki status --cost`.
- **Single-line log entries** per LLM call via `log.log_llm_call()`. Format:
  `## [<ISO-Z>] llm-call | op=<o> | model=<m> | in_tokens=<n> | out_tokens=<n> | cache_read=<n> | cache_creation=<n> | duration_ms=<n> | cost_usd=<f>`
- **`log.append` now lock-protected** (`file_lock("log")`). Closes ARCH-1
  racy-log bug as a side-effect.
- **`LOCK_NAMES` + `LOCK_NAME_PREFIXES` registry** at `src/gateway/locking.py`
  enumerates sanctioned locks (`wiki-author`, `nlm-registry`, `log`, `index`,
  `ingest-*`, `schedule-*`). Informational today; future milestones may
  enforce at `file_lock(...)` call sites.
- **5 LLM call sites migrated** to use `call_with_usage` + emit telemetry:
  - `filter/semantic.py:score()` → `op=filter`
  - `ops/ingest.py:520` (plan authorship) → `op=plan_authorship`
  - `research/query_planner.py:134` → `op=plan_query_planner`
  - `research/orchestrator.py:_infer_domain` → `op=plan_domain_inference`
  - `ops/bootstrap_domain.py:176` → `op=plan_bootstrap_domain`
  - `vlm.py:describe()` → `op=vlm`
- **`wiki status` 7-day usage block.** New `_aggregate_llm_usage()` parses
  `llm-call` log lines, buckets by op, renders totals + per-op call counts.
- **`wiki status --cost` flag** adds USD line from the `cost_usd` field on
  each log entry. Tokens always shown; cost behind the flag per C5.

### K2 — MCP-CLI parity

- **12 new `wiki_*` MCP tools** added to `src/gateway/mcp_server.py`:
  `wiki_research`, `wiki_lint`, `wiki_batch_ingest`, `wiki_bootstrap_domain`,
  `wiki_discover_domains`, `wiki_promote_domain`, `wiki_reject_proposal`,
  `wiki_cite`, `wiki_backfill_examples`, `wiki_finetune`, `wiki_poll`,
  `wiki_poll_list`. All follow the existing `@mcp.tool() → _serialize()`
  pattern.
- **`wiki_research` mirrors all CLI flags** per D3 (one tool, all the
  flag-options; mutual-exclusivity enforced inside the underlying
  `research()` op).
- **`wiki_cite` additions param is typed objects** per C6:
  `list[{"line": int, "source_id": str}]`. Internally converted to the
  tuple shape `cite()` expects.
- **`wiki_demote_domain` omitted** per C4 (destructive cross-state action).
  Documented in the new `CLI_ONLY` allowlist constant.
- **`CLI_ONLY` allowlist** at `mcp_server.CLI_ONLY` lists the intentionally
  unexposed CLI ops: `watch`, `mcp-serve`, `serve`, `migrate`,
  `demote-domain`.
- **Parity CI test** at `tests/gateway/test_mcp_parity.py`. Asserts every
  `cli.IMPLEMENTED` entry minus `CLI_ONLY` has a matching `wiki_*` tool.
  This is the forcing function for K1: any new op without an MCP wrapper
  will fail this test.

  model=claude-haiku-4-5-20251001 | in_tokens=10 | out_tokens=281 |
  cache_read=0 | cache_creation=54728 | duration_ms=5938 |
  cost_usd=0.069825

```
$ wiki status
...
LLM usage (last 7 days): 1 calls
  total: in=10 · out=281 · cache_read=0 · cache_creation=54,728
  by op: hand_test_k5=1
```

```
$ wiki status --cost
...
LLM usage (last 7 days): 1 calls
  total: in=10 · out=281 · cache_read=0 · cache_creation=54,728
  by op: hand_test_k5=1
  reported cost (from claude envelope): $0.0698
  (USD estimate is approximate; authoritative billing lives with Anthropic)
```

**Finding revealed by telemetry:** the probe with no `--system-prompt`
inherited Claude Code's default system prompt, consuming 54,728 cache-creation
tokens at Haiku's $1.00/M-tok cache-creation rate ≈ $0.055 of the $0.07 cost.
This validates M44's `--system-prompt` strategy: production filter/plan/VLM
calls pass `--system-prompt` explicitly and avoid this cache cost. K5
makes the cost difference visible for the first time.
