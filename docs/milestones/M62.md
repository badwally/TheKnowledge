### ONT-10 — Source pages manifest-only

`wiki_pages.py`: source page type `required_sections=()`, `citation_grounded=False`. Source pages are citation targets, not content-bearing pages — semantic content lives in `raw/` (verbatim) and synthesis pages (LLM extraction).

`WIKI.md § 4.3`: updated to manifest-only spec.

### INT-14 — `wiki digest` daily content brief

`src/gateway/ops/wiki_digest.py`: `build_wiki_digest(hours, stale_days)` returns a channel-agnostic markdown string with four sections:
- **New sources (last Nh)** — grouped by domain, title, source_id
- **New synthesis (last Nh)** — slug + title + domain
- **Stale drafts (>Nd)** — count with `wiki finalize-batch --suggest` pointer
- **Triage queue** — count with `wiki triage list` pointer

`wiki digest [--hours N] [--stale-days N] [--out PATH]` CLI. `wiki_digest` MCP tool. 8 tests in `tests/gateway/test_int14_wiki_digest.py`.

Never sends anything — Message Send Gate is absolute.
