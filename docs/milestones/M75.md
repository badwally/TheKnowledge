## Delivered

### QUAL-10 — Held-out calibration set for filter policy evaluation

Replaces the statistically meaningless n=5 filter-calibration check with a real held-out gold set. Calibration sets live at `.knowledge/policies/<domain>/calibration_set.yaml` as a YAML list of manually-labelled examples (`source_id`, `decision`, `rationale`). Recommended size: 30–50 per domain.

**New module:** `src/gateway/ops/calibration.py`

- `CalibrationEntry` dataclass: `source_id`, `decision` (include|exclude), `rationale`
- `load_calibration_set(domain)` — reads `calibration_set.yaml`; returns `[]` if absent
- `add_calibration_entry(domain, entry)` — appends; idempotent on `source_id`
- `score_calibration(domain, inclusion_criteria, exclusion_criteria, client)` — for each calibration entry, invokes the filter client with the candidate criteria + source excerpt; computes precision/recall/F1/accuracy vs. ground truth; returns `CalibrationMetrics | None`
- `CalibrationMetrics` dataclass: n_examples, correct, incorrect, TP/FP/FN, precision, recall, f1, accuracy

**`distill_prompt()` updated** (`src/gateway/ops/finetune.py`):
- After distilling the candidate policy, calls `score_calibration()` with the new criteria
- If a calibration set exists, adds `calibration_metrics` block (n_examples, precision, recall, f1, accuracy, scored_at) to the candidate YAML
- Returns `DistillResult.calibration_f1` (float | None)

**CLI additions** (`wiki finetune`):
- `--check-calibration` — shows calibration set size and split for a domain (no LLM)
- `--add-calibration include|exclude --source <source_id> --domain <d> [--rationale "..."]` — appends a calibration entry

**Test coverage:** 15 tests in `tests/gateway/test_qual10_calibration.py`.

**ARCH-14 update:** `ops/calibration.py` added to `_ALLOWED_WRITE_TEXT` (reads `raw_dir()` for source excerpts; writes only to `.knowledge/policies/`, not wiki/raw).
