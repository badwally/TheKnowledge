### INT-19 — Slack source poller

Polls configured Slack channels for notable messages and writes them to `raw/note/` as canonical note sources. Completes the CLAUDE.md "queued pollers" set — all five originally planned API-only source pollers are now shipped.

**`pollers/slack.py` (new) — `SlackSourcePoller`:**

- `name = "slack"`, `source_type = "note"`
- Config at `.knowledge/pollers/slack/config.yaml`:
  ```yaml
  channels:
    - channel_id: "C12345ABC"
      name: "knowledge-notes"    # for display/slug only
      domain: "research"         # optional wiki domain tag
  min_length: 200                # min body chars for standalone messages
  include_threads: true          # append thread replies to message body
  max_messages: 100              # per channel per run
  ```
- Auth: `SLACK_BOT_TOKEN` env var; required scopes: `channels:history`, `groups:history` (private channels), `channels:read`, `groups:read`
- Cursor at `.knowledge/pollers/slack/cursor.yaml` tracking latest `ts` per channel_id
- **Ingest filter:** messages with `len(text) >= min_length` OR `reply_count > 0` (thread roots); short standalone messages are skipped (cursor still advances)
- **Thread bodies:** if `include_threads=true` and a message is a thread root, fetches replies via `conversations.replies` and appends them as `> <reply_text>` to the body
- Slug format: `note-slack-<sha256(channel_id + ts)[:12]>` — matches WIKI.md § 6.1
- Custom frontmatter fields: `slack_channel_id`, `slack_channel_name`, `slack_ts`, `posted_at` (does not break validator — extra fields pass through)
- `run(*, fetch_history=None, fetch_replies=None)` — injectable callables for testing; fall back to live Slack API calls with the bot token

**Slack API usage:**
- `GET conversations.history?channel={id}&oldest={cursor}&limit={n}` — paginated message fetch
- `GET conversations.replies?channel={id}&ts={ts}&limit=200` — thread replies
- No explicit rate-limit sleeps; typical config sizes stay within Tier 3 limits

**`pollers/__init__.py` updated:** `SlackSourcePoller` registered as `"slack"`.
