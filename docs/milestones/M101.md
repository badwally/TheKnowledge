## Deliverable

`wiki evaluate --all-domains`: runs evaluation for every domain with a `goldens.yaml` file,
returns aggregate summary. Weekly `evaluate-weekly` cron job registered in
`.knowledge/schedule.yaml` (Sundays 03:00 UTC).

## Implementation

**`src/gateway/evaluate/persistence.py`** (modified)
- `domains_with_goldens()`: returns sorted list of domain slugs with a `goldens.yaml` in `.knowledge/eval/<domain>/`

**`src/gateway/ops/evaluate_op.py`** (modified)
- `evaluate_op(all_domains=False)`: when True, delegates to `_evaluate_all_domains`
- `_evaluate_all_domains(limit)`: iterates `domains_with_goldens()`, calls `evaluate_op(domain=d)` for each, returns aggregate `OperationResult` with per-domain summaries and partial-failure support
- Error message updated to mention `--all-domains`

**`src/gateway/cli.py`** (modified)
- `--all-domains` flag added to `wiki evaluate` parser
- `_run_evaluate` passes `all_domains=getattr(ns, "all_domains", False)`
- Epilog updated with `wiki evaluate --all-domains` example

**`.knowledge/schedule.yaml`** (modified)
- `evaluate-weekly` job: `cron: 0 3 * * 0`, `command: wiki evaluate --all-domains`, `cooldown_seconds: 7200`
