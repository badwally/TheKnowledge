## Deliverable

TOOL-15: `wiki ask-corpus <domain> "<question>"` — direct query interface into a domain's NLM corpus.

## Implementation

**`src/gateway/cli.py`**
- Added `"ask-corpus"` to `SUBCOMMANDS` dict and `IMPLEMENTED` set
- Added `p_ask_corpus` parser: positional `domain` and `question` args, `--no-draft` flag, epilog examples
- Added dispatch in `main()`: `if ns.subcommand == "ask-corpus": return _run_ask_corpus_cmd(ns)`
- Added `_run_ask_corpus_cmd(ns)`: delegates to `query(ns.question, domain=ns.domain, draft=not ns.no_draft)`

**`src/gateway/mcp_server.py`**
- Added `@mcp.tool() wiki_ask_corpus(domain, question, draft=True)`: same delegation, simpler MCP interface

**Design note:** TOOL-15 is intentionally a thin wrapper. `ops/query.py` already handles NLM notebook queries via `NlmClient.notebook_query`; the value of `ask-corpus` is domain-first ergonomics and `draft=True` as the sensible default for corpus queries.
