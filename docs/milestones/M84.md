## Deliverable

TOK-10: low-stakes sources (voice/note type, or any body < 2 KB) route to Sonnet 4.6 for wiki authorship instead of Opus 4.7. Reduces cost ~5x for short content with equivalent schema-compliance and citation-grounding.

## Implementation

**`src/gateway/llm/config.py`**
- `plan_authorship_small` added to `Stage` Literal type
- `DEFAULT_PLAN_AUTHORSHIP_SMALL_MODEL = "claude-sonnet-4-6"` constant
- `model_for("plan_authorship_small")` → Sonnet 4.6

**`src/gateway/ops/ingest.py`**
- `_SMALL_SOURCE_TYPES = frozenset({"voice", "note"})` — always route to small
- `_SMALL_BODY_THRESHOLD = 2048` — bytes; short web clips use Sonnet
- `_authorship_model(front, body) -> str` — routing helper
- `_invoke_plan_and_apply` uses `_authorship_model` when creating default `ClaudeCLIPlanClient`

**`tests/gateway/test_tok10_authorship_model_split.py`** — 12 tests

## Routing logic

```
source_type in {"voice", "note"}  →  plan_authorship_small (Sonnet)
len(body.encode()) < 2048         →  plan_authorship_small (Sonnet)
otherwise                         →  plan_authorship (Opus)
```

Voice transcripts and Notion/Slack/Apple Notes snippets don't warrant Opus-level reasoning. Web clippings under 2 KB are similarly bounded. Long-form research (arxiv, pdf, pubmed) stays on Opus.
