# M58 — Phase 2 Round D (ONT-6, TOK-12, AGT-1, AGT-2)

**Date:** 2026-05-25
**Tag:** `m58-phase2-round-d`
**Branch:** `phase2-round-d` → merged to `main`

Four independent items: one ontology enforcement (ONT-6), one research salvage (TOK-12), two new agents (AGT-1, AGT-2).

## Goal

Close four open gaps in the Phase 2 roadmap:

- **ONT-6**: created_at/last_updated are documented as required in WIKI.md but never validated. 0 of 769 entities had last_updated; enforce at write time + migration script.
- **TOK-12**: long research runs fail partway through and lose all progress. Per-branch salvage files let the orchestrator resume without re-querying NLM.
- **AGT-1**: newly ingested sources land in raw/ with no domain assignment. Inbox-triage agent dispatches them automatically; ambiguous cases enter a review queue.
- **AGT-2**: stale drafts accumulate; no systematic route to finalization. Draft-closer agent finalizes easy wins (1:1 citation) and writes escalation entries for hard cases.

## Components shipped

**ONT-6 — Timestamp enforcement (`dd1d877`).** `created_at` and `last_updated` added to `required_fields` for entity/concept/synthesis in `wiki_pages.py`. `sources_count` added for synthesis. `validate_timestamps()` in `validator.py` checks ISO-8601 parseability (error rule `"timestamp-format"`). `apply_plan.py` auto-stamps missing timestamps before validation so existing callers don't break. `concept_add`, `query`, `finalize` ops stamp timestamps on write. `contested` added to `MUTABLE_SOURCE_FIELDS` (QUAL-3 dependency). Migration `migrations/0004-backfill-timestamps.py` backfills via `git log --diff-filter=A` / `git log`. +13 tests in `tests/gateway/test_ont6_timestamps.py`.

**TOK-12 — Salvage-on-partial-failure (`3397a41`).** `src/gateway/research/analysis.py` gains: `FINDINGS_STALE_HOURS = 24`, `_slugify_branch()` (collision-safe via hash suffix), `_write_branch_finding()` writes `nlm/findings/<session_id>/<slug>.json` after each `_investigate_branch()` call (success or error), `load_branch_findings()` returns None for absent dirs or stale files (>24h). `analyze()` gains `session_id` (enables persistence) and `prefetched_findings` (skips NLM for cached branches). `_extract_taxonomy()` also handles JSON-format answers alongside THEME/SUBTHEME text. +9 tests in `tests/gateway/test_tok12_salvage.py`.

**AGT-1 — Inbox-triage agent (`56c5c6a`).** `src/gateway/agents/inbox_triage.py`: `run_triage(source_id)` → `TriageResult`. Domain-present path: runs filter.score(), persists to source frontmatter. Domain-absent path: keyword-overlap against all `policies/*/policy.yaml` descriptions; confidence ≥ 0.6 for exactly one → tag + filter; ambiguous/none → "needs-domain", no filter. Review-band sources (threshold_review ≤ score < threshold_include) written to `.knowledge/triage/<source_id>.yaml`. `triage_list()` / `triage_depth()` public API. `wiki triage list` CLI + `wiki_triage` MCP tool. Status shows triage depth when queue is non-empty. NEVER calls filter-correct. +11 tests in `tests/gateway/test_agt1_inbox_triage.py`.

**AGT-2 — Draft-closer agent (`558fe23`).** `src/gateway/agents/draft_closer.py`: `run_draft_closer()` → `DraftCloserResult`. Reads stale drafts via `stale_drafts.run()`. Easy-win check: no body line has 2+ `[[sources/<id>]]` patterns → try `finalize()`; success → finalized, failure → escalated. Hard cases: escalation entry in log.md with pre-computed `wiki cite` invocations. Per-domain summary written to log.md after each run. `DRAFT_CLOSER_SCHEDULE` constant (8am UTC daily cron entry). `wiki draft-close run` CLI + `wiki_draft_close` MCP tool. NEVER finalizes when a claim line cites multiple sources. +7 tests in `tests/gateway/test_agt2_draft_closer.py`.
