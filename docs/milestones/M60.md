### A2 — Event bus chain verification (AGT-9)

`WatcherDaemon._process` now emits `ingest.complete` via `events.emit()` on every successful ingest. Payload: `{"source_id": "<stem>"}`. Agent: `"watcher"`. Correlation ID: UUID4. Exception-safe: event failure logs a warning and does not abort the ingest.

No direct watcher → inbox-triage coupling — decoupled via event bus. Verified by `test_no_direct_watcher_to_triage_coupling` (source inspection).

5 new tests in `tests/gateway/test_a2_event_bus_chain.py`:
- `test_watcher_emits_ingest_complete_on_success`
- `test_watcher_does_not_emit_on_failure`
- `test_subscribe_inbox_triage_returns_ingest_complete_event`
- `test_subscribe_inbox_triage_ignores_filter_scored_events`
- `test_no_direct_watcher_to_triage_coupling`
