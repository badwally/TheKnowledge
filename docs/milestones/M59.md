**DOC-7 — docs/adr/ (`5dc0971`).** 15 architecture decision records + README index:
- ADR-001: Filesystem as database (rejects PostgreSQL, SQLite, git-native stores)
- ADR-002: Gateway as single mutator (rejects direct-write convention)
- ADR-003: NotebookLM as gateway-mediated service (rejects direct NLM tool calls)
- ADR-004: Plan before write for incremental ingest (rejects silent accumulation)
- ADR-005: Citation grounding mandatory (rejects optional attribution)
- ADR-006: Draft mode as default for research authoring (rejects strict-only mode)
- ADR-007: Per-agent processes over single daemon (rejects always-on scheduler process)
- ADR-008: Prompt caching via separate API key (rejects --bare / Max OAuth for subprocess calls)
- ADR-009: Session-state discipline via docs/session-state.md (rejects context-window-only state)
- ADR-010: Filter as Haiku-tier LLM (rejects Sonnet for borderline cases)
- ADR-011: Source immutability — body never mutated post-ingest (rejects in-place correction)
- ADR-012: Wikilink syntax for citations (rejects numeric footnotes, inline URLs)
- ADR-013: Readwise v3 API over separate pollers (rejects per-service Pocket/Instapaper pollers)
- ADR-014: Slug as stable identifier (rejects UUID, content hash, integers)
- ADR-015: Citation allowlist as versioned YAML (rejects hardcoded Python lists)
