## Design notes

- AGT-4 uses Claude CLI (via `ClaudeCLIFilterClient`) rather than NLM corpus sweep. The existing `lint/contradictions.py` LLM call is the same infrastructure. NLM not needed — the wiki claim extraction + LLM judge pattern is cleaner and doesn't require NLM notebooks to be populated.
- `contradiction-sweep` is exposed as an MCP tool (unlike `briefing-cron`) because triggering a domain-scoped sweep is a legitimate agent action.
- `synthesizes: []` intentional: contradiction pages synthesize from wiki pages, not raw sources. ONT-11 lint warning is acceptable for auto-generated draft pages.
