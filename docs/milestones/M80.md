## Delivered

### SRCH-1 — `wiki search` full-text search

Implements `wiki search`, promoting it from a long-standing stub (since M0) to a working grep-based fulltext search over all wiki and raw markdown files.

**`src/gateway/ops/search.py` (new):**

- `search(query, *, scope, domain, page_type, limit)` — case-insensitive substring match; scope is `"wiki"`, `"raw"`, or `"all"` (default); optional domain and page_type filters; default limit 20
- **Ranking (descending):** score 3 = title match, 2 = slug match, 1 = body match; ties broken by title alphabetically
- `SearchHit` dataclass: `path`, `slug`, `title`, `page_type`, `domain`, `score`, `snippet`
- `SearchResult` dataclass: `hits`, `query`, `total`
- `format_results(result, *, relative_to=None)` — human-readable CLI output with relative paths and snippets
- No external dependencies — stdlib `re` and `pathlib` only; suitable for current corpus size (<5k files)

**CLI:**
- `wiki search "<query>" [--scope wiki|raw|all] [--domain DOMAIN] [--type PAGE_TYPE] [--limit N]`
- Exits 0 on results, 1 on no results
- Added to `IMPLEMENTED` set

**MCP:** `wiki_search(query, scope, domain, page_type, limit)` — returns `{query, total, hits: [{path, slug, title, page_type, domain, score, snippet}]}`.

**`tests/gateway/test_smoke.py`** — updated the "unimplemented stub" test from `search` to `index` (which remains a stub).
