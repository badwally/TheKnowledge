## Deliverable

`wiki routine daily-domain-digest [--domain SLUG]` — the poll-triage-synthesize loop from TOOL-12. Finds sources ingested in the last 24 hours for a domain, summarizes with an LLM call, and writes a draft synthesis page at `wiki/synthesis/daily-<domain>-<YYYY-MM-DD>.md`. Scheduled daily at 06:00 UTC via `.knowledge/schedule.yaml`.

## Implementation

**`src/gateway/ops/daily_digest.py`** — new module

- `run_daily_domain_digest(domain, *, client, date_str, lookback_hours) → OperationResult`
  - Idempotency: if today's page already exists, returns no-op with `reason: already_exists`
  - Threshold: if < 1 new sources found in lookback window, skips with `reason: insufficient_sources`
  - Injectable `FilterClient` — avoids real LLM calls in tests
  - Builds `synthesizes:` + `## Included works` to satisfy validator's `validate_synthesizes_integrity`
  - Draft page (`draft: true`) — requires `wiki finalize` to promote
- `run_all_domains(*, client, date_str, lookback_hours) → OperationResult` — iterates all `policies_dir()/*/policy.yaml` blessed domains

**`src/gateway/cli.py`** — `wiki routine daily-domain-digest [--domain SLUG] [--date YYYY-MM-DD] [--lookback-hours N]`; `"routine"` in IMPLEMENTED

**`src/gateway/mcp_server.py`** — `wiki_routine(routine, domain, date, lookback_hours)` MCP tool

**`.knowledge/schedule.yaml`** — `daily-domain-digest` cron job at `0 6 * * *` (daily 06:00 UTC)

**`tests/gateway/test_tool12_daily_digest.py`** — 19 tests

## Design decisions

- Used `FilterClient.call()` injection pattern (same as contradiction_sweeper) — avoids subprocess calls in tests
- `synthesizes:` built from source IDs in order; `## Included works` mirrors it 1:1 — passes `validate_synthesizes_integrity` at write time
- All sources tier is `sources/` (single tier) — no mixed-tier issue
- Output always `draft: true` — user must finalize to promote to wiki canon
