## Delivered

### INT-18 — Notion source poller

Reads Notion pages and databases into `raw/note/` as canonical note sources for the wiki ingest pipeline. Completes the CLAUDE.md "API-only-source pollers" set (Apple Notes, Gmail, RSS, Notion; Slack remains queued).

**`notion_client.py` additions (read path):**

- `get_page(page_id)` — fetch page metadata and properties
- `get_page_blocks(page_id)` — paginated block children fetch
- `search_pages(query, filter_body)` — search pages accessible to the integration
- `blocks_to_markdown(blocks)` — converts Notion block list to markdown; supports: `paragraph`, `heading_1/2/3`, `bulleted_list_item`, `numbered_list_item`, `to_do` (checked/unchecked), `code` (with language), `quote`, `callout`, `divider`, `image` (external/file), `bookmark`; unsupported blocks silently skipped
- `_rich_text_to_md(rich_text)` — inline annotation support: bold, italic, strikethrough, code, link; plain_text extraction

**`pollers/notion.py` (new) — `NotionSourcePoller`:**

- `name = "notion"`, `source_type = "note"`
- Config at `.knowledge/pollers/notion/config.yaml`:
  ```yaml
  pages:
    - page_id: "<notion-page-id>"
      domain: "my-domain"       # optional
      title_override: ""        # optional
  databases:
    - database_id: "<db-id>"
      domain: "research"
  max_pages: 50                 # per-run limit
  ```
- Cursor at `.knowledge/pollers/notion/cursor.yaml` tracking `last_edited_time` per page_id
- Slug format: `note-notion-<sha256(page_id)[:12]>` — matches WIKI.md § 6.1
- Individual pages: fetches metadata + blocks, skips if `last_edited_time` unchanged since cursor
- Database pages: queries with `last_edited_time > cursor` filter; fetches blocks per page
- Writes canonical `raw/note/` markdown with `content_hash`, `source_app: notion`, `domains:`, etc.
- `run(*, client=None)` — injectable client for testing; falls back to `NOTION_TOKEN` env var
- Registered as `"notion"` in `pollers/__init__._REGISTRY`

**`CLAUDE.md` updated:** forward-looking pollers note now lists Notion as shipped; Slack remains queued.

**Hand-test deferred** per the M5 pattern (requires live NOTION_TOKEN + configured workspace).
