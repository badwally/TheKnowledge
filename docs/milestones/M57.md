**Date:** 2026-05-25
**Tag:** `m57-phase2-round-c`

Two independent integration pollers. No dependency between them; INT-8 shipped first (smaller).

## Goal

Extend the poller infrastructure to cover two high-value automatic ingestion sources:

- INT-8: 20+ sibling projects at `~/code/*/` contain CLAUDE.md, README.md, and docs that describe system state. Making `wiki query "what's the architecture of chief-of-staff"` work without manual ingestion.
- INT-9: Readwise v3 consolidates highlights from Kindle, Pocket, Instapaper, Twitter saves, and web articles in a single endpoint — one poller replaces the deferred INT-1/INT-2/INT-3 chain.

## Components shipped

**INT-8 — Repo-metadata poller (`b150ed5`).** `src/gateway/pollers/repo_metadata.py`: `RepoMetadataPoller` (name=`"repo-metadata"`, source_type=`"note"`). Targets: `~/code/*/README.md`, `~/code/*/CLAUDE.md`, `~/code/*/docs/*.md`. Excluded dirs: `node_modules`, `.venv`, `__pycache__`, `.git`, `vendor`, `dist`, `build`. Cursor: `{str(abs_path): sha256_hash}` in `.knowledge/pollers/repo-metadata/cursor.yaml`; files with unchanged hash are skipped on re-run. Slug format: `note-repo-<project>-<rel_slug>-<hash8>`. Auto-domain tagging: if `.knowledge/policies/<project>.yaml` exists, `domains: [<project>]`. Missing `~/code/` dir returns clean success with 0 fetched. Registered in `_REGISTRY`. +11 tests in `tests/gateway/test_pollers_repo_metadata.py`.

**INT-9 — Readwise poller (`48ed35c`).** `src/gateway/pollers/readwise.py`: `ReadwisePoller` (name=`"readwise"`, source_type=`"note"`). API: `GET https://readwise.io/api/v3/list/` with `Authorization: Token <READWISE_TOKEN>`. Cursor: `last_updated_after` (initial `"2020-01-01T00:00:00Z"`) advanced to `max(document["updated"])` after each batch. Pagination: follows `next` URL until null. One `raw/note/note-readwise-<id>.md` file per document; re-runs update the `## Highlights` section if content hash changed (idempotent). Body: title, author, category, `## Highlights` bullets with inline note annotation. Fails fast with `success=False` and clear error if `READWISE_TOKEN` absent. Registered in `_REGISTRY`. +11 tests in `tests/gateway/test_pollers_readwise.py`.
