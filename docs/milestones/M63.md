### INT-13: `wiki agenda` — calendar-aware meeting prep

**Files changed:**
- `src/gateway/ops/wiki_agenda.py` (new) — `build_agenda(date_str, events)` + `write_agenda()`
- `src/gateway/paths.py` — `agenda_dir()` → `wiki/agenda/`
- `src/gateway/wiki_pages.py` — `agenda` page type (ephemeral, not citation-grounded)
- `src/gateway/cli.py` — `wiki agenda [--date] [--events-json] [--out] [--no-write]`
- `src/gateway/mcp_server.py` — `wiki_agenda(date, events, write)` MCP tool
- `tests/gateway/test_int13_wiki_agenda.py` (new) — 8 tests

**Behavior:**
- `build_agenda(date_str, events)` takes pre-fetched calendar event dicts (Google Calendar API format)
- Filters events to those with ≥2 attendees
- For each event: normalizes attendee display names to wiki entity slugs; fetches `## Summary` excerpt from matching `wiki/entities/` pages; matches event title/description keywords to `wiki/concepts/` slugs; appends concept excerpts
- Returns channel-agnostic markdown briefing (drafts only, no auto-send anywhere)
- `write_agenda()` writes `wiki/agenda/<date>.md` with `type: agenda` frontmatter
- CLI default: writes `wiki/agenda/<date>.md`; `--no-write` prints to stdout
- MCP tool: agent pre-fetches calendar events via `mcp__claude_ai_Google_Calendar__list_events`, passes list to `wiki_agenda`

**Acceptance criteria met:** `wiki agenda [--date YYYY-MM-DD]`; output `wiki/agenda/<date>.md`; drafts only, no auto-send.
