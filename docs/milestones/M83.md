## Deliverable

`/api/sources` endpoint — sortable, filterable table of all raw sources. Closes the gap where the web UI had no view into `raw/` or `wiki/sources/`.

## Implementation

**`src/gateway/web/routes/sources.py`** — new module
- `GET /api/sources` with query params: `q` (substring search over title/ID/body), `domain`, `type`, `limit` (default 200, max 1000)
- Returns `list[SourceRecord]` — each record carries `source_id`, `source_type`, `title`, `domains`, `ingested_at`, `filter_score`, `link_status`, `word_count`, `draft`
- Case-insensitive substring match across title, source ID, and body text
- Iterates `raw/**/*.md`; gracefully skips unreadable files

**`src/gateway/web/schemas.py`** — `SourceRecord` model added

**`src/gateway/web/app.py`** — `sources_routes.router` registered at `/api/sources`
