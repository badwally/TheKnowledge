## Design notes

- **DB layout: one DB per domain.** Considered one DB with a domain column. Rejected: domain isolation, per-domain Notion views, and wiki policy boundaries all favor separate DBs. Cross-domain queries are not a use case for a read-only mirror.
- **No MCP tools for Notion auth calls.** The Notion MCP tools available in Claude.ai sessions cannot be called from Python gateway code. `urllib.request` with `NOTION_TOKEN` is the correct integration point.
- **`contradiction-drift` is CLI_ONLY.** Scheduler owns the nightly invocation. Agents should not trigger corpus-wide contradiction re-scans ad hoc.
- **`publish-notion` is an MCP tool.** Agents legitimately need to mirror a specific domain to Notion on demand.
- **`_collect_pages` uses frontmatter `domains:` + `domain:` both.** Legacy pages may use singular `domain:` field; both are checked for maximum compatibility.
