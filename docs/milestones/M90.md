## Deliverable

TOOL-11: `/api/inbox` web endpoint exposing `raw/inbox/` pending files and
`raw/inbox/_failed/` failed files with retry capability.

## Implementation

**`src/gateway/web/routes/inbox.py`**
- `GET /api/inbox` → `InboxDetailResponse`: pending items (filename, size, mtime,
  sniffed type/title/url from frontmatter) + failed items (original name, failed_at
  parsed from timestamp prefix, reason from `.reason.txt` sidecar, size)
- `POST /api/inbox/retry/{filename}` → moves failed file back to inbox, removes
  reason sidecar; 404 if not found, 409 if original name already pending

**`src/gateway/web/schemas.py`**
- `InboxPendingItem`, `InboxFailedItem`, `InboxDetailResponse`, `RetryResponse`

**`src/gateway/web/app.py`**
