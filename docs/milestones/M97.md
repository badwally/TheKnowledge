## Deliverable

`wiki fix-wikilinks` repairs broken wikilinks across all wiki pages:
- Broken `[[sources/...]]` citations → **removed** (dead citation; source page does not exist)
- Broken `[[entities/...]]` / `[[concepts/...]]` links → **downgraded to aliased form** `[[target|slug]]` (ERROR → WARNING; preserves forward-reference intent)

Run result: 136 pages touched, 195 source links removed, 82 entity/concept links downgraded.
