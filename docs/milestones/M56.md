Four items. Dependency order: AGT-9 → AGT-14; ONT-2 [M55] → ONT-3 → QUAL-3. AGT-9 and ONT-3 were independent and developed concurrently in the same session.

## Goal

Infrastructure for autonomous agent coordination (event bus + activity log) and a structured lifecycle for surfacing and resolving contradictions between sources (page type + lint + ops).

- AGT-9: agents need to react to gateway events without polling. A synchronous filesystem bus is sufficient because every gateway process is short-lived; no daemon required.
- ONT-3: contradictions between sources were tracked only in LLM-detected claim pairs (contradictions lint). Structuring them as wiki pages makes them actionable — resolvable with audit trail.
- AGT-14: operator visibility into what agents did in the last 24h. Draft synthesis page only — Message Send Gate is absolute, no auto-delivery.
- QUAL-3: the resolution workflow is the point of ONT-3. Setting `contested: true` on sources with ≥2 open contradictions closes the loop between detection and curation.

## Components shipped

**AGT-9 — Filesystem event bus (`49a7412`).** `src/gateway/events.py`: `emit()`, `subscribe()`, `list_events()`. Event store: `.knowledge/events/<YYYY-MM-DD>/<seq:04d>.json`. Subscription config at `.knowledge/agents/<name>.yaml` (agent, subscribes_to, debounce_s, max_concurrent_runs). Debounce: second emit of same (event_type, agent) within debounce_s window is suppressed. `events_dir()` and `agents_dir()` added to `paths.py`. `"agent"` prefix registered in `LOCK_NAME_PREFIXES`. +14 tests in `test_events.py`.

**ONT-3 — Contradiction page type (`9b2c90d`).** `"contradiction"` added to `PAGE_SCHEMAS` (directory: `wiki/contradictions`, required_fields: type/slug/parties/severity/status, citation_grounded=False). `CONTRADICTION_SEVERITY_ENUM` (major/minor/methodological) and `CONTRADICTION_STATUS_ENUM` (open/investigating/resolved/wontfix) in `validator.py`. `validate_contradiction_frontmatter()` wired into `validate_wiki_page`. New lint check `src/gateway/lint/contradiction_pages.py` registered as `"contradiction-pages"`: walks `wiki/contradictions/*.md`, surfaces open+major pages as `SEVERITY_WARNING`. Migration `migrations/0003-migrate-contradictions-jsonl.py` reads `.knowledge/contradictions.jsonl` (absent in this repo — no-op). +18 tests in `test_ont3_contradiction.py`.

**AGT-14 — Agent-log + daily digest (`bf84837`, shared commit with QUAL-3).** `src/gateway/ops/agent_log.py`: `aggregate(since_hours)` returns per-agent counts + top-5 event payloads; `build_digest_page(date_str)` builds a draft wiki synthesis page. `DIGEST_SCHEDULE_ENTRY` constant defines the 7am UTC daily job (draft only — no auto-send). CLI: `wiki agent-log --since 24h|48h|7d`. MCP: `wiki_agent_log`. +11 tests in `test_agent_log.py`.

**QUAL-3 — Contradiction surfacing and resolution workflow (`bf84837`).** `src/gateway/ops/contradiction.py`: `list_contradictions(severity, status)` and `resolve_contradiction(slug, status, note)`. `resolve` updates frontmatter in-place; sets `contested: true` on source pages with ≥2 remaining open contradictions. `wiki status` now includes open contradiction counts by severity. CLI: `wiki contradiction list [--severity] [--status]` and `wiki contradiction resolve <slug> --status --note`. MCP: `wiki_contradiction`. +13 tests in `test_qual3_contradiction.py`.
