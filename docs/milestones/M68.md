### ONT-4 — entity_kind migration op

- `src/gateway/ops/backfill_entity_kinds.py` (new): `backfill_entity_kinds(dry_run=False)`.
  - Walks `wiki/entities/**/*.md`. Skips pages whose `entity_kind` is already in `ENTITY_KIND_ENUM`.
  - Applies `_KIND_MAP` to remap ~35 known legacy free-text aliases (publication → paper, policy_document → statute, guideline → standard, company → organization, etc.).
  - Unmapped values not in the enum fall through to `"other"`.
  - Writes via `write_atomic`. Idempotent: second run skips all pages.
  - `--dry-run` reports without writing.
  - Returns `OperationResult` with `updated / skipped / errors` counts in summary.
  - `wiki backfill-entity-kinds [--dry-run]` CLI; `CLI_ONLY` in MCP (one-time migration, agents must not trigger bulk wiki rewrites).
  - 12 tests in `test_ont4_entity_kind_migration.py`.

## Design notes

- `_canonical_kind()` applies a two-step lookup: exact match in enum → `_KIND_MAP` lookup (normalized with lowercase + hyphen normalization) → fallback `"other"`. This is intentionally conservative: `"other"` is always safe and surfaced by schema-drift for human review.
- Backfill ops are `CLI_ONLY` to prevent agents from triggering unsupervised bulk wiki rewrites.
- Both ops are idempotent by design: second run on a clean wiki reports all-skipped.
