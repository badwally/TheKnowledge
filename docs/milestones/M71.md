## Design notes

- `serialize()` injection: uses a `stamped` dict with `schema_version` as the first key, then spreads the original dict. `sort_keys=False` preserves insertion order in yaml.safe_dump, so `schema_version` appears first in the serialized YAML.
- Mixed-tier synthesizes resolution: when body wikilinks reference both `sources/` and `synthesis/` targets, the backfill uses sources-only. This follows the validator's strict tier rule and is the more common case (synthesis pages aggregating primary sources).
- Lint escalation timing: `synthesizes-coverage` was WARNING since M45. Escalating to ERROR in M71 because the backfill helper now provides an automated path to fix the 56 affected pages. Users who want to suppress the lint can run `wiki backfill-synthesizes` first.
