## Deliverable

`wiki index --rebuild` regenerates `index.md` with a structured, domain-grouped catalog replacing the flat "Recent ingests" list.

## Implementation

**`src/gateway/ops/index_rebuild.py`** — new module

- `rebuild(*, dry_run=False) → OperationResult` — top-level entry point; uses `write_atomic` for safe writes
- `_collect_domains()` — scans `wiki/mocs/` for MOC files; slug = domain
- `_count_raw_sources()` — walks `raw/**/*.md`; counts per `domains:` frontmatter field; untagged → `__untagged__`
- `_collect_wiki_pages()` — returns `{domain: {page_type: [slug, ...]}}` using explicit `_DIR_TO_TYPE` mapping
- `_find_cross_domain_pages()` — wiki pages tagged with 2+ domains
- `_lint_orphan_count()` — delegates to `gateway.lint.orphans` for health section
- `_render_index()` — produces WIKI.md § 7 format: header stats, domain sections, cross-domain, health

Key design decision: used explicit `_DIR_TO_TYPE` dict instead of `subdir.name.rstrip("s")`. The `rstrip` approach corrupts "synthesis" → "synthesi" because `rstrip` removes all trailing 's' chars, not just the last one.

**`src/gateway/cli.py`** — `wiki index [--rebuild] [--dry-run]` subparser; `"index"` in `IMPLEMENTED`

**`src/gateway/mcp_server.py`** — `wiki_index(dry_run=False)` MCP tool (named `wiki_index` to match parity convention `wiki_{cli_op}`)

**`tests/gateway/test_srch2_index_rebuild.py`** — 17 tests covering all helper functions and `rebuild()` end-to-end

**`tests/gateway/test_smoke.py`** — stub test updated from `index` to `migrate`

3. MCP tool named `wiki_index_rebuild` doesn't satisfy parity test (expected `wiki_index`); renamed to match convention
