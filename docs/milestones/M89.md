## Deliverable

AGT-8: monthly `wiki routine filter-calibrator` checks each domain's example-bank
count against the distillation threshold (500 examples). For any domain that crosses
the threshold for the first time, emits a `calibration-distill-ready` log event
recommending `wiki finetune --distill --domain <domain>`. Never executes distillation
— that is a user decision.

## Implementation

**`src/gateway/ops/filter_calibrator.py`**
- `run_filter_calibrator()` → `OperationResult`
- Calls `trigger_states_all()` from finetune ops
- For newly-ready domains: writes `calibration-distill-ready` log event with the
  specific command to run; persists seen set to `.knowledge/filter_calibrator_logged.yaml`
  so the event fires only once per domain

**`src/gateway/cli.py`**
- `wiki routine filter-calibrator` dispatches to `run_filter_calibrator()`
- `filter-calibrator` subparser added to `p_routine_sub`
- Help text updated to list both available routines

**`.knowledge/schedule.yaml`**
- `filter-calibrator` job: `cron: 0 2 1 * *` (1st of month, 02:00 UTC)

**`tests/gateway/test_agt8_filter_calibrator.py`** — 10 tests
