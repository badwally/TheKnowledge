# M100 — Phase 9 Round A (synthesis question quality — domain topic + source preview injection)

**Tag:** `02716fe`
**Branch:** `main`
**Tests:** 1812 → 1822 (+10), 0 regressions

## Deliverable

Improved `_synthesis_question` in `discharge_orphans.py` to produce grounded synthesis
questions by incorporating domain policy topic and source content preview, replacing the
previous content-free title-only prompt.

## Implementation

**`src/gateway/ops/discharge_orphans.py`** (modified)
- `_source_preview(front, body)`: extracts a 300-char preview from `meta.abstract` → `meta.excerpt` → `description` → body fallback
- `_synthesis_question(source, domain_topic)`: builds richer question using preview + domain context; falls back gracefully when either is absent
- `_orphan_sources_for_domain`: captures body (was `_`) and includes `preview` in returned dicts
- `discharge_orphans`: soft-loads domain policy via `policy_exists` / `load_policy`; passes `domain_topic` to `_synthesis_question`; `PolicyError` is silently swallowed (improvement is additive, not required)
- `from gateway.filter.policy import PolicyError, load_policy, policy_exists` moved to module-level imports for patchability

## Tests

`tests/gateway/test_m99_discharge_orphans.py` — 10 new tests: `_synthesis_question` with preview+topic, preview-only, topic-only, fallback; `_source_preview` using abstract, excerpt, body, abstract-over-excerpt priority; `discharge_orphans` uses policy when available.
