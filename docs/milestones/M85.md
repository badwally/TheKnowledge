## Deliverable

TOOL-8: morning triage surface. `wiki daily` CLI outputs a structured triage list
(stale drafts, orphan sources, inbox count, recently ingested). `/today` web route
returns the same data as JSON for the web UI.

## Implementation

**`src/gateway/ops/daily_review.py`**
- `DailyReviewResult` dataclass: `stale_drafts`, `orphan_sources`, `recently_ingested`, `inbox_count`, `inbox_failed`, `triage_queue_depth`, `as_of`
- `run_daily_review(*, lookback_hours, stale_days, orphan_limit)` — read-only collector
- `format_daily_review(result)` — terminal-friendly triage text
- `run_daily_review_op()` → `OperationResult`

**`src/gateway/web/routes/today.py`**

## Key design

- **Orphan detection**: raw sources where `wiki_pages: []` — O(n_raw_sources), no wiki scan needed
- **Stale drafts**: `draft: true` + `draft_started_at` or file mtime older than threshold
- **No LLM calls**: pure read-only filesystem aggregation; fast enough for shell invocation
