## Deliverable

`wiki routine discharge-orphans --domain <slug> [--limit N] [--dry-run]`:
batch-synthesizes draft wiki pages for orphaned raw sources in a domain.

An orphan source is a raw/* file with `wiki_pages: []` — ingested but with
no wiki page citing it yet. For each qualifying source (filtered by domain,
capped at `--limit`), the routine generates a synthesizing question from
the source's title and calls `query()` to produce a draft synthesis page
that naturally cites it.

Post-finalization, each discharged source gains a `wiki_pages:` entry,
removing it from the orphan list. This fulfills the CLAUDE.md guidance:
"Source-orphan tail discharges via `wiki query` synthesis loops."

## Implementation

**`src/gateway/ops/discharge_orphans.py`** (new)
- `discharge_orphans(domain, limit=10, dry_run=False) -> OperationResult`
- `_orphan_sources_for_domain(domain, limit)`: scans raw/* for sources with `wiki_pages: []` tagged to the target domain
- `_synthesis_question(source)`: generates a synthesizing question from the source title
- Delegates synthesis to `query(question, domain=domain, draft=True)` per source

**CLI:** `wiki routine discharge-orphans --domain SLUG [--limit N] [--dry-run]` — wired as a sub-command of `wiki routine` alongside `daily-domain-digest` and `filter-calibrator`
