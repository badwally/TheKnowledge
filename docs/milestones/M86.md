## Deliverable

AGT-7: `/wiki-cite` capture-to-cite slash command wired. From any `~/code/*` repo,
pass a quote + URL; the gateway ingests the source (idempotent) and adds the
citation to the target wiki page in one MCP call.

## Implementation

**`src/gateway/ops/cite_capture.py`**
- `_normalize_url(url)` — strips trailing slash, query params, lowercases
- `_find_source_by_url(url)` → `(source_id, source_type) | None` — scans `raw/` frontmatter
- `_ensure_source_wiki_page(source_id, source_type)` → bool — backfills `wiki/sources/<id>.md`
- `_tokenize(text)` — 4+ char tokens, stop-word filtered
- `_find_target_by_overlap(quote)` → wiki path or None — slug/title token-overlap
- `cite_capture(quote, url, target_page=None, *, filter_client=None)` → `OperationResult`

**`src/gateway/cli.py`**

## Key design

- **Idempotency**: URL dedup via `raw/` scan before calling ingest; safe to re-run.
- **Auto-target**: token-overlap between quote words and slug+title tokens. Requires ≥1 hit; fails with informative error if none (user specifies `--target`).
- **No filter bypass**: ingest uses `draft=True`; filter "no-domain" decision still creates wiki/sources page. Backfill covers filter-excluded edge case.
