Five independent items. No shared files. All five were safe to develop in any order within the round; the first item (TOK-4) sets the billing-cost pattern for the round.

## Goal

Token efficiency, ontological rigour, and configuration stability. Each item had a clear ROI argument before the round started:

- TOK-4: existing-pages block was the dominant token cost in every `wiki ingest --with-plan` call. 30 full pages × 5 KB each = 150 KB per call; two-stage select reduces this to ≤10 KB.
- ONT-2: disputes/extends relations were encoded informally; formalizing 8 CiTO verbs lets Round B (contradiction workflow, QUAL-3) reason structurally over cited evidence.
- ONT-4: 24 free-text entity_kind values broke downstream faceting and made programmatic filtering unreliable.
- ONT-8: 190-char slug-as-sentence made the Levenshtein-2 similarity check meaningless; slug is a stable key, not a title.
- ARCH-10: NLM compat phrases were patched silently in Python; moving to YAML makes additions auditable and diff-reviewable.

## Components shipped

**TOK-4 — `_gather_existing_pages` two-stage select (`08337d7`).** Stage 1 sends frontmatter + 200-char snippet per page (≤10 KB total cap). Exception: ≤5 matching pages → full bodies sent (small-wiki path preserves current behavior). Constants: `_STAGE1_SNIPPET_CHARS = 200`, `_STAGE1_FULL_BODY_THRESHOLD = 5`, `_STAGE1_PROMPT_CAP = 10_000`. +4 tests in `test_ingest.py`.

**ONT-2 — CiTO 8-verb typed citations (`15bc70b`).** `_CITO_VERBS` frozenset in `citations.py`. `_ALIASED_SOURCE_RE` matches `[[sources/<id>|<verb>]]`. `validate_citation_verbs()` in `validator.py` emits `SEVERITY_WARNING` for unknown verbs. Wired into `validate_wiki_page`. WIKI.md § 5.6 documents the extension. +5 tests in `test_validator.py`.

**ONT-4 — `entity_kind` controlled vocabulary (`d8d80a5`).** `ENTITY_KIND_ENUM` (12 values) in `validator.py`. New entity pages with unknown `entity_kind` are hard-rejected (`SEVERITY_ERROR`). `migrations/0002-migrate-entity-kinds.py` maps 25 legacy free-text values to the enum (idempotent, dry-run default). +5 tests in `test_validator.py`.

**ONT-8 — Slug length cap 80 chars (`a3e7325`).** `_MAX_SLUG_LEN = 80` in `validator.py`. `validate_wiki_page_frontmatter` rejects new slugs >80 chars; `--force-long-slug` flag downgrades to warning. Lint check `src/gateway/lint/long_slugs.py` surfaces grandfathered legacy slugs as `SEVERITY_WARNING`. Registered as `long-slugs` in lint orchestrator. WIKI.md § 6.2 documents the cap and override. +4 tests in `test_validator.py`.

**ARCH-10 — Citation allowlist to versioned YAML (`c586c70`).** `_STRUCTURAL_FRAME_LABELS` and `_AGGREGATE_FRAMING_OPENERS_RE` moved from hardcoded Python to `src/gateway/data/citations_allowlist.yaml` (v1). `citations.py` loads at import time. Behavioral equivalence confirmed by 14 existing pinned tests. WIKI.md § 5.2 updated. +5 tests in `test_authorship.py`.
