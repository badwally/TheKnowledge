# M53 — Phase 1 Round B (TOK-1, TOK-3, TOK-6, TOK-7)

**Date:** 2026-05-25
**Tag:** `m53-phase1-round-b`
**Branch:** `phase1-round-b` → merged to `main`

Four token-efficiency items targeting redundant LLM calls, unbounded context loads, and repeated transcription work. All test-first. No new external dependencies.

## Goal

Reduce per-operation token consumption and prevent unsafe prompt construction before the multi-model (Round C) phase. The items address concrete waste patterns identified in M50–M51 hand-tests:

- TOK-1: `cache_read=0` in filter calls traced to 60-token system prompt below the 1024-token floor; already fixed in M50.1.
- TOK-3: `build_system_prompt()` was called N times per filter batch (once per candidate); policy + examples are batch-invariant.
- TOK-6: mlx-whisper ran on the same audio file on every convert; no disk cache existed.
- TOK-7: `log.md` and `index.md` are unbounded and must never be loaded wholesale into LLM prompts; no guard existed.

## Components shipped

**TOK-1 — cache_read=0 diagnosis (`95afa59`, doc only).** Root cause: the system prompt at filter time was ~60 tokens, below Anthropic's 1024-token minimum for prompt caching. M50.1 (`7ad5996`) already fixed the underlying issue by moving `wiki_context` into the `user_prompt_prefix` block with `cache_control: {type: "ephemeral"}`, raising the cacheable block above the floor. No code change needed in Round B. Diagnosis documented at `docs/M52-tok1-cache-diagnosis.md`.

**TOK-3 — memoize filter system-prompt build (`773c0f9`).** `gateway.filter.semantic.score()` gains `_prebuilt_system: str | None = None`; when provided, skips `build_system_prompt()`. `gateway.research.orchestrator._run_filter()` calls `_build_filter_system_prompt(policy, examples)` once before the `ThreadPoolExecutor`, then passes the result into every `filter_score()` invocation. For a batch of N candidates this reduces `build_system_prompt()` calls from N to 1. +1 test in `test_filter.py` (prebuilt skips build); +1 test in `test_research_orchestrator.py` (build called exactly once across 3 candidates). Three existing `_score` stubs in orchestrator tests updated to accept `_prebuilt_system=None`.

**TOK-6 — transcription cache at disk (`1300db2`).** `gateway.transcription` gains:
- `TranscriptionResult.from_dict()` classmethod for JSON deserialization
- `load_transcript_cache(cache_dir, sha256hex, model) -> TranscriptionResult | None`: reads `<cache_dir>/<sha256hex>.json`, validates model name match, returns None on miss/mismatch/parse error
- `save_transcript_cache(cache_dir, sha256hex, result)`: mkdir + write JSON

Voice and audiobook converters compute `sha256hex = hashlib.sha256(raw_bytes).hexdigest()` before calling mlx-whisper and store cache at `raw/<type>/_transcripts/<sha256hex>.json`. On re-convert of the same audio file the transcription is recovered from disk and mlx-whisper is not called. Cache is keyed by content hash so renamed files still hit. +2 tests in `test_transcription.py`: second call skips transcription, different files produce separate cache entries.

**TOK-7 — assert_safe_for_prompt guard (`122149a`).** `gateway.paths` gains `PromptGuardError(RuntimeError)` and `assert_safe_for_prompt(path)`. Raises `PromptGuardError` if `path.name` is `"log.md"` or `"index.md"` — both files are unbounded in size and must never be loaded wholesale into LLM prompts. CLAUDE.md hard prohibition added in the session-state discipline setup (commit `a24d9b5`) names the two safe alternatives: `_tail_log_entries()` for log excerpts, `evaluate.wiki_context.load_wiki_context()` for wiki context. +3 tests in `test_log_and_locking.py`: raises for `log_path()`, raises for `index_path()`, passes for a wiki page.

## Infrastructure shipped (same branch)

**Session-state discipline (`a24d9b5`).** `docs/session-state.md` is load-bearing across compactions. PreCompact hook at `.claude/hooks/precompact-snapshot.sh` instructs the agent to write and commit the file before context is compressed. SessionStart hook at `.claude/hooks/session-start-reanchor.sh` instructs re-anchor on resume. CLAUDE.md `## Session-state discipline` rule added.
